## 本次锁定口径（写进三份意见，不再改）

1. **韶塘材料＝广东省内 IDC 机楼现状支撑文件**，不是第二套申报，不是套版笔误。按 320 号附件 2（八），省内已投产规模及利用率本应作附件提交，该材料在体系上正属此列，**不删**；错在摘要表把其 200MW／244.3 亩／6 栋／80000 架标为“本次申报范围”，属把现状支撑数字误写入申报边界。本次窗口／两高只审**里水 36MW**。
2. **窗口材料按“窗口指导需要交什么”审**，即 320 号附件 2 八部分逐块核对，不按可研或两高清单硬套。
3. **腾龙属大型及以上，全部纳入窗口指导、不分投资主体**，有限责任公司（外国法人独资）不豁免；按一期 136MW 计仍为 7500kW 阈值的 18.13 倍。本次不出腾龙窗口意见文件。
4. **绿电要本址物理电量路径**；绿证与省外合同不能无条件顶年度占比。320 号项下“绿电超 80%”是优先支持门槛，不是已实现结论。
5. **电信“不投服务器”不能把 IT 电量从两高边界拿掉**；反向亦不成立，IT 电量计入不等于服务器成为本期资产。
6. **广东《节能审查和碳排放评价实施办法》（据称 2026-08-20）红头未核**：三份意见均不引其条文，涉及节能审查／碳排放评价程序处一律标「待核」。
7. **标准架 2.5kW、IT MW、FP16 三套口径分开声明**：标准架只用于 320 号附件 1 分档折合，不做推算填充未披露项。
