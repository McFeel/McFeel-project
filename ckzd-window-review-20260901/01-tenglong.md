# 腾龙湾区数据中心项目窗口审查

## 结论

**现稿不宜出具肯定性窗口意见。** 本次申请口径尚未唯一：整体宣称 **202MW**，机柜明细算得 **202.92768MW（约202.93MW）**，同时又列一期 **136MW**。在申请边界、同址需求、能耗替代、绿电权益、敏感点环境约束、主体资金责任未闭环前，不能将其中任一数字直接作为无条件批复口径。

> 页码说明：所给原文引述未提供页码，以下均如实标注“页码稿中未见”，以章节或字段定位。

## [高]问题

### [高] 1. 本次申请MW不唯一，整体、机柜算术与一期并列

- **位置**：项目概况及建设规模（页码稿中未见）。
- **原文**：“宣称202MW / 总投41.81亿，一期136MW / 31.52亿。”“480个14.4kW风冷 + 7056个27.78kW冷板液冷，IT约202.9MW，折合标准机柜约8.12万个。”
- **问题**：机柜算术为 `480×14.4kW + 7056×27.78kW = 202927.68kW`，即 **202.92768MW**，可解释为“约202.9MW”；但它对应整体 **202MW**，不能同时证明一期 **136MW**。一期对应哪些楼栋、模块、机柜、投资、用地和年电量，稿中未见。
- **追问**：本次窗口申请究竟是 **202MW** 还是一期 **136MW**？请只保留一个申请值，并提交该值对应的机柜清单、楼栋/模块、投资、用地、变电容量、年电量和投产计划。

### [高] 2. 需求侧完全未形成“客户—地址—MW—交付期”闭环

- **位置**：需求章节（页码及具体章节稿中未见）。
- **原文**：所给腾龙原文引述中，已签约需求、意向需求、客户地址及合同清单均**稿中未见**。
- **问题**：约 **202.9MW**、折合约 **8.12万个标准机柜** 的建设规模，没有可核对的同址已签约或意向需求支撑；已签约与意向也无法分层。
- **追问**：请逐项列明客户、合同/意向性质、服务地址是否为西樵、承诺IT MW、机架数、上架时间和退出条款；若无已签约需求，请明确不得把意向量表述为已锁定消纳。

### [高] 3. 绿电100%、争取20%与“买绿证替代”是三套口径

- **位置**：背景章、2.6绿电供给、结论章、两高替代专章（页码稿中未见）。
- **原文**：“能耗替代：买绿证。”“结论章承诺绿电100%；背景章另引争取20%。”“拟与售电公司签约，通过电力交易中心采购，实现100%绿电。”
- **问题**：“拟签约”不是已落实合同；**100%** 与“争取 **20%**”冲突；电力交易电量、绿证和环境权益不能混写为同一项，也未见数量、年度、项目用电匹配及权益归属。
- **追问**：请按年度分别列物理结算绿电电量、绿证数量、环境权益归属及注销主体，并说明买绿证为何可作为本项目能耗替代；若尚未签约，凭什么在结论中承诺100%？

### [高] 4. 两高专章虽有数字，但替代来源和一期边界未闭合

- **位置**：章4及两高替代专章（页码稿中未见）。
- **原文**：“年综合能耗tce（当量256355.86，等价591746.09）与两高替代专章。”“单位工业增加值能耗4.569tce/万元，高于佛山规上2.42。”“能耗替代：买绿证。”
- **问题**：现稿承认项目能耗强度高于所引比较值，但以买绿证说明替代；同时未说明 **256355.86tce / 591746.09tce** 对应整体202MW还是一期136MW。替代量、来源、可用年度及落实凭证稿中未见。
- **追问**：两组tce各自采用什么折标边界、对应多少MW和哪一期？替代量从何项目、何年度取得，是否已有可核验文件？若仅购绿证，能否满足稿内所称“两高替代”要求的依据何在？

### [高] 5. 学校、居住敏感点与160m³油罐未见环境安全闭环

- **位置**：项目选址及柴发系统（页码稿中未见）。
- **原文**：“东侧多层居住，南侧太平中学大道，西侧地块西侧为太平中学操场。”“埋地油罐160m³。”
- **问题**：项目紧邻居住和学校操场，并设置大体量埋地油罐；所给引述未见与边界/敏感点距离、柴发废气和噪声预测、油罐防渗防火、危化管理、事故场景及环评结论。
- **追问**：请在总图上标出住宅、教学区、操场、柴发机组、排气口和油罐的最近距离，并提交噪声、废气、防渗、防火及事故风险结论；如不满足，如何调整总图？

### [高] 6. “新建”与2024年主体工程已竣工转固冲突

- **位置**：项目性质、主体及财务信息（页码稿中未见）。
- **原文**：“性质写新建。”“发展公司2024年主体工程竣工转固1.34亿；三年营业收入为零。”
- **问题**：若2024年已有“主体工程竣工转固”，则本次“新建”的既有资产边界、建设进度、是否先建后报、是否计入 **41.81亿元 / 31.52亿元** 均需解释；三年营收为零也使出资能力需进一步核实。
- **追问**：1.34亿元转固资产具体是什么、位于何处、是否属于本项目？已完工程是否计入本次投资和窗口申请？若答“不属于”，请提供资产项目和地址对应关系。

### [高] 7. 投资、建设、运营主体分列，责任和资金链稿中未闭合

- **位置**：主体及公司介绍（页码稿中未见）。
- **原文**：“主体：广东腾龙数据科技有限公司（外国法人独资）；投资还有腾龙数据科技发展；运营鹏城金云；背后普洛斯。”
- **问题**：申请主体、投资主体和运营主体不是同一口径；土地/资产权属、建设合同、运营授权、电力与绿电交易、能耗责任、收入归属、资本金及债务安排在所给引述中均稿中未见。
- **追问**：谁申请、谁拿地、谁投资、谁持有资产、谁签电力和客户合同、谁承担能耗与环境责任？请用合同和资金流把三家公司闭合到 **41.81亿元 / 31.52亿元**。

## [中]问题

### [中] 8. PUE算术可对上，但年加权和负荷率依据未见

- **位置**：节能指标（页码稿中未见）。
- **原文**：“PUE设计1.173；年电20.8589亿kWh / IT 17.7765亿。”
- **问题**：`20.8589÷17.7765≈1.1734`，与设计 **1.173** 基本一致；但逐月负荷率、爬坡期、部分负载效率、液冷实际投建比例及年加权计算表稿中未见，不能仅凭两项年电量证明投运年均值。
- **追问**：请给出一期和整体各自的月度IT负荷、制冷及其他辅助用电，说明 **1.173** 是设计点、满载值还是全年加权值；偏离设计负荷时PUE如何变化？

### [中] 9. 1#、2#模块数不同却同为48MW，模块功率口径不一致

- **位置**：楼栋/模块配置（页码稿中未见）。
- **原文**：“1#智算120模块 / 48MW；2#同写48MW但96模块。”
- **问题**：1#折算每模块 **0.4MW**，2#折算每模块 **0.5MW**；若模块规格不同，稿中未见解释。该差异会影响机柜数、配电、制冷和一期136MW拆分。
- **追问**：两栋模块定义和单模块机柜数是否相同？若不同，请列设备表；若相同，哪一处MW或模块数有误？

### [中] 10. 公司规划机架口径与本项目机柜口径未衔接

- **位置**：公司介绍、项目建设内容（页码稿中未见）。
- **原文**：“公司介绍：规划6kW机架20000个。”“480个14.4kW风冷 + 7056个27.78kW冷板液冷……折合标准机柜约8.12万个。”
- **问题**：公司介绍口径为 **120MW**，项目明细约 **202.93MW**；“6kW机架”“实际机柜”“标准机柜”三者关系稿中未说明。
- **追问**：20000个6kW机架是本项目、公司其他项目还是旧版方案？请统一实际机柜、标准机柜、平均功率和IT MW换算表。

### [中] 11. “腾讯自研 N+X 2.0”与申报主体关系不明，存在套版风险

- **位置**：液冷机房章节（页码稿中未见）。
- **原文**：“液冷机房写‘腾讯自研 N+X 2.0’。”
- **问题**：申报、投资及运营主体均非腾讯；所给引述未见腾讯作为客户、供货方或授权方的依据，也未说明该方案是否确为本期建设内容。
- **追问**：该表述来自已确定设备、客户技术规范还是复制案例？若为本项目方案，请出示技术来源、授权/采购关系和本期设备清单；否则删除其作为项目亮点的证明效力。

### [中] 12. 国产芯片与本期建设内容的对应关系稿中未见

- **位置**：算力和设备方案（页码及章节稿中未见）。
- **原文**：所给腾龙原文引述中，国产芯片型号、数量、算力测算和采购主体均**稿中未见**。
- **问题**：现有引述只有高功率风冷/液冷机柜配置，无法判断国产芯片承诺是否存在、是否落到本期设备，亦无法据此核验算力。
- **追问**：若窗口材料主张国产化，请列芯片型号、数量、精度口径、单卡/整机算力、采购主体及对应机柜；若不购服务器，应明确该内容只是客户适配条件而非本期建设量。
