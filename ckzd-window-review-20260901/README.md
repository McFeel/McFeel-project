# 2026-09-02 窗口指导独立重审总览

> 结论先行：两项目现稿均不具备直接出具肯定性窗口意见的条件。电信应按 **36MW** 审，不得被摘要 **200MW** 带跑；腾龙须先在整体 **202MW（机柜算术约202.93MW）** 与一期 **136MW** 之间冻结本次申请边界。

## 腾龙湾区（南海西樵）：5行

1. **申请边界**：正文宣称整体 **202MW / 41.81亿元**、一期 **136MW / 31.52亿元**；机柜为 **480个14.4kW + 7056个27.78kW**，合计约 **202.93MW**。本次究竟批整体还是一期，稿中未闭合。
2. **需求闭环**：所给引述中未见已签约客户、意向客户、需求地址、交付期及对应MW，无法验证约 **8.12万个标准机柜** 的消纳。
3. **PUE与能耗**：**20.8589亿kWh ÷ 17.7765亿kWh ≈ 1.173**，算术可对上；但负荷率、逐月爬坡和年加权边界稿中未见，且单位工业增加值能耗 **4.569tce/万元** 高于所引佛山规上 **2.42**。
4. **绿电与环境**：一处承诺绿电 **100%**，一处称“争取 **20%**”，同时以买绿证作能耗替代；东侧居住、邻太平中学操场并设 **160m³** 埋地油罐，敏感点约束未闭环。
5. **主体、资金、套版与政策**：投资、建设、运营主体分列；发展公司2024年已有 **1.34亿元** 主体工程转固且三年营收为零，与“新建”待核；“腾讯自研 N+X 2.0”需说明来源；所引政策规划期止于2025年。

## 中国电信佛山数据中心（南海里水）：5行

1. **申请边界**：本次应锁定 **36MW**、**14400个标准机架**、**46.55亩**、新建1栋、投资 **94638万元**；摘要 **200MW / 80000个机架 / 244.3亩 / 6栋** 与“韶塘园区”同现，不能作为里水申报量。
2. **需求闭环**：索引“已签约 **36MW**”、3.6摘要“已签约 **200MW**”、3.7.1“**62MW**”互相冲突；邦程 **7MW** 写在东莞，唯颐 **55MW** 附件仅为“合作需求书”。
3. **PUE与能耗**：满载测算 **PUE 1.199**，但50%负载微模块材料为 **1.245**，液冷机柜“本期暂不建”；节能审查及附件1.6、1.11均“项目未启动，暂无”，年加权PUE和能评未形成。
4. **绿电、土地与环境**：承诺绿电 **>80%**，附件却为2025年韶关园区合同；存量用地性质待调整，院内存在综合楼、酒店、幼儿园，柴发油罐资料稿中未见。
5. **财务与建设内容**：“其他收入”把 **3.3万/P/月** 直接算成约 **32210万元** 并纳入达产年收入；收入减成本仅 **22549.6万元**，却列利润总额 **29561万元**，且利润表、现金流表为空；服务器不在本期投资，但算力又以昇腾950DT/910C两套口径支撑。

**专家一句建议：先退回补齐“唯一申报MW—对应机架/投资/用地—同址有效需求—年度能耗与年加权PUE—可核验绿电权益—土地环境与资金财务”一套闭环数据，再分别判断是否具备肯定性窗口意见。**
