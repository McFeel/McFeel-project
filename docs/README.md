# Cloud 可读记忆说明

## 结论

Cursor Cloud **无跨会话记忆**。能被下一轮读到的，只有本仓库已合并或本任务已挂上的文件。习惯、门禁、工作法写进本目录；个案口径写进项目夹，不升格为通用规则。

## 三层各写什么

| 层 | 位置 | 写什么 | 不写什么 |
| --- | --- | --- | --- |
| 入口 | 仓库根 `AGENTS.md` | 指向本说明、专责、写作法；优先级 | 项目主体、金额、定稿路径 |
| 专责框架 | `docs/specialist-memory/` | 职责、派 Cloud 必挂、硬门禁、短踩坑 | 某项目的最新数字或对外口径 |
| 长稿工作法 | `docs/writing-method-codex.md` | 结论先行、证据分层、另存不盖、未校验不称最终 | 把全文粘进派单 |
| 个案 | 项目夹（用户指定目录） | 本项目口径、底稿、改口、收资清单 | 升格进专责当通用规则 |

## 怎么挂

- **专责任务**：只挂对应 `docs/specialist-memory/*.md`。跨专责交接，先核交付形态，再决定谁主笔。
- **正式中文长稿**：挂 `docs/writing-method-codex.md`。文秘任务再挂 `docs/specialist-memory/文秘.md`、底稿路径、本轮改口。
- **派单**：只引上述路径，不粘全文。本轮禁止项写在派单正文最前。
- **成果**：进本仓库 PR。默认另存新文件。

## 维护

- 通用门禁改这里；个案改口改项目夹。
- 经验可进专责「踩坑样本」，限短句，不带定稿路径当规则。
- 科技 / 国重专责：可用经验须在 24 小时内沉淀到本目录，且不越职责边界。
