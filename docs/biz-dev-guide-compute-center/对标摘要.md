## 二、写入政策红线章的三件硬货（骨架第 2 章已落）

1. 发改高技〔2025〕320 号窗口指导：大型及以上进窗、不分投资主体；未过窗口不得备案 / 能评 / 网络接入（2.1、停机条件首条）。
2. 广东节能审查 + 碳排放评价：数据中心（含智算）列重点领域，2026 年新办法；文号红头【待核】（2.7）。
3. 2.5kW 标准架（仅 320 号分档折合用）与 ≥12kW 高密口径分列，且与 IT MW、FP16 算力互不折算（总旁注 3、1.4、2.2）。

## 三、两点合并使用说明

1. 上海导则与 Coloprice 手册**合并用、不重复当唯一底**：导则出「分类分档」的骨，手册出「电力优先 + 逐步核对」的肉；骨架每节四件套即两者合成。
2. Orrick 与建纬合并覆盖「钱从哪来、责任到哪止」：融资增信排查（6.4）与投建营分期边界、退出安排（5 章、6.7）互为对照，避免只写工程不写退出。

## 四、可建可售章的对标纪律

第 4 章只列产业已有形态 + 红线（机柜托管、算力租赁、卡时 / 机时、调度、绿电碳、合同能源）；南网产品包以 4.8 留空表占位（待核 #13），经审批后方可填入，**禁止编造**产品包名称、报价表与客户名册。
