## 二、写入政策红线章的硬货（骨架第 2 章已落结构）

1. 发改高技〔2025〕320 号窗口指导（①）：大型及以上进窗、不分投资主体；未过窗口不得备案 / 能评 / 网络接入——此条为基于 320 号的**正式政策判断**（2.1）。不得推进电力接入承诺、不得签署以项目获批为前提的商务条款，标为**公司内部停机规则**，不写成全国统一法定门槛。
2. 广东节能审查 + 碳排放评价（①）：数据中心（含智算）列重点领域，2026 年新办法；文号红头【待核】（2.7）。
3. 2.5kW 标准架（仅 320 号分档折合用）与 ≥12kW 高密口径分列，且与 IT MW、FP16 算力互不折算（总旁注 3、1.4、2.2）。
4. 绿电占比超过 80%：属于优先支持方向，适用条件、核算口径和兑现方式须按项目所在地及最新政策确认；不写成硬性门槛（总旁注 8、2.6）。
5. 区域路径（①）：2.3.1 内蒙古 / 青海 / 重庆十二字段矩阵；三地政策原件索引见 8.4.1。26 号转载条款、7 号 / 11 号省政府页、88 号 / 1843 号起步区已按条款号或官方 HTML 登记；官方 PDF 页码与未打开文件仍标【待核】。

## 三、两点合并使用说明（结构参考）

1. 地方导则与电力优先手册**拟合并用、不重复当唯一底**：导则出「分类分档」的骨，手册出「电力优先 + 逐步核对」的肉；骨架每节四件套即两者合成。未核原件前不称已锁。
2. 供电融资与投建营材料拟合并覆盖「钱从哪来、责任到哪止」：融资增信排查（6.4）与投建营分期边界、退出安排（5 章、6.7）互为对照，避免只写工程不写退出。

第 4 章只列产业已有形态 + 红线（机柜托管、算力租赁、卡时 / 机时、调度、绿电碳、合同能源）；公司产品包以 4.8 留空表占位（待核 #13），经审批后方可填入，**禁止编造**产品包名称、报价表与客户名册。
