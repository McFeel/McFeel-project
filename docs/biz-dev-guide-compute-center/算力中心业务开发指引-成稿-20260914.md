## 0 本文件是什么、给谁用、不覆盖什么

**结论句**：本指引是内部业务开发的办事底本，回答「这单能不能做、按什么红线做、拿什么去卖、建完怎么交」四个问题；它不是销售话术本，不是对外白皮书，不是可研模板。

**要问的数 / 要收材料**

- 使用者所在条线（市场 / 立项 / 能源 / 交接）与本单所处阶段（线索 / 立项 / 谈判 / 交付）。
- 本单是否涉及对外出口材料。若是，停用本指引措辞，转文秘按对外口径另拟；对外口径须经总管交用户确认，本成稿不直接外发。

**红线 / 停机条件**

- 本文任何段落不得直接复制进对外材料、合作文本或合同。（公司内部停机规则）
- 「找谁 / 怎么开口」类内容不入本指引任何层级目录。（公司内部停机规则）

**展开**

### 0.1 定位与适用范围

本文件对内共用。市场部用来判定「这单落在哪个政策格子、有没有可售形态」；立项口用来冻结规模、主体和投资边界；能源口用来锁电力、绿电与计量；交接口用来收齐协议与退出安排。四条线读同一套红线，不各写各的口径。

适用对象是公司拟介入的算力中心、数据中心及相关能源服务线索，含新建、改造、合营与服务介入。不适用对象见 0.2。

### 0.2 不覆盖什么

本指引不覆盖：对外话术与开口脚本；可研深度测算与收益承诺；法律意见替代；公司战略规划文本；技术方案（机电、制冷、AI 栈）；客户名册与标准报价。缺项进第 8 章待核表，不在正文编造。

### 0.3 与既有文件的关系

权威源只认：公开政策原件、属地书面确认、电网书面意见、公司已批制度。内部窗口指导复盘、内部投资边界复盘、乙方市场对照报告只作来源脚注类别，不展开成章，不写项目名。写作法约束事实 / 口径 / 假设 / 待核分层。本文件更新按第 8 章归口；不列内部记忆路径，不挂会话或外部知识库链接。

### 0.4 阅读方法

每节先读结论句，再收数、对红线，最后按展开动作执行。凡写停机，须能辨出是正式政策要求、属地执行要求，还是公司内部停机规则，禁止把公司内部控制写成全国统一法定门槛。待核项保持【待核】字样，销项只走 8.5 表，不在正文默销。

## 1 对象与边界

**结论句**：本指引覆盖智算中心、传统 IDC、云 / 算力服务三类对象，以及自建、合营、供电 + 绿电、能源底座、存量改造、算力调度六类介入方式；公司介入深度以「能源电力见长、算力运营审慎」为默认边界，是否自持运营 IDC【待核，公司文件未写死前不预设】。

**要问的数 / 要收材料**

- 项目对象归类：智算 / IDC / 云，按客户主营与设备形态判定，不按客户自称。
- 介入方式归类：自建、合营（含 SPV）、供电 + 绿电、机电 / 能源底座、存量改造、调度 / 运营服务，六选一或组合，须在立项材料首页写明。
- 公司投资边界与客户（或 SPV）边界的划分表：谁出资、谁持有、谁运营、谁签电力合同。

**红线 / 停机条件**

- 签署主体、合作实施主体、股权变更后股东，三者不得默认同一；改口后全文跟改，删并存旧称。（公司内部停机规则）
- 公司出资额、设备清单合计、控制数，不得写成已确认投资或合同额。（公司内部停机规则）
- 合营模式下，法律意见（一致行动人、关联交易、代持）未出具前，不得对外承诺股比与治理安排。（公司内部停机规则；来源：内部投资边界复盘材料，见 8.3.1，不展开）

**展开**

### 1.1 三类对象定义与判定

| 对象 | 判定要件（须同时看，不看自称） | 本指引默认关注点 |
|---|---|---|
| 智算中心 | 以加速卡 / 高密机柜为主，交付算力或训练推理服务 | 窗口分档、PUE、绿电、电力容量、卡时口径 |
| 传统 IDC | 以机柜托管 / 带宽 / 机位为主，客户自带或租赁服务器 | 上架率、SLA、电价传导、托管租约 |
| 云 / 算力服务 | 以云资源、调度或算网服务为主，不一定自持机房 | 调度计量、互联要求、公司角色【待核 #7】 |

一单可跨两类。立项首页只写一个主对象，其余作附属，避免分档和能评各说各话。

每格须在立项材料写明四方：出资方 / 持有方 / 运营方 / 电力合同签署方。空格不得用「原则上我方」带过。

| 介入方式 | 出资方 | 持有方 | 运营方 | 电力合同签署方 |
|---|---|---|---|---|
| 自建 | 公司或公司指定主体 | 公司或指定主体 | 【待核：是否自持运营】 | 须书面指定，不得口头 |
| 合营（含 SPV） | 按股东协议；未出具法律意见前不填股比 | SPV 或约定主体 | 按章程 / 委托运营协议 | 须与股东协议同时冻结 |
| 供电 + 绿电 | 电源 / 绿电侧按合同 | 电源资产按合同 | 供电服务方按合同 | 电网侧与用户侧分列 |

例外仍守三条：主体三分列；控制数不升格合同额；法律意见前置。来源类别见 8.3.1，不展开个案。

## 2 政策与布局红线 ★

**结论句**：现行监管的第一道闸不是能评而是「政策位置」——根据发改高技〔2025〕320 号，大型及以上算力中心全部纳入窗口指导（不分投资主体，外资不豁免）；国家枢纽节点外原则上不得新建大型及以上算力中心（「超大型」是否单列以附件 1 原文为准，页码【待核】）。未过窗口，备案、节能审查、网络接入均无从谈起——此条为基于 320 号的政策判断。业务人员接单第一件事是核规模分档与选址落在哪个政策格子，而不是先谈电价。内蒙古 / 青海 / 重庆的属地路径见 2.3.1，三地条件不得互抄。

**要问的数 / 要收材料**

- 项目 IT 总功率（kW / MW）与机柜清单（数量 × 单柜功率，逐项相加复核）；折合标准架数 = IT kW ÷ 2.5kW，仅用于分档。
- 政策分档判定：≥7500kW（3000 标准架）即大型档起点，属「大型及以上」，必进窗口指导；中型、小型阈值及服务器采购金额判定维度【待核 #1】。
- 选址是否位于国家枢纽节点 / 数据中心集群起步区——申报必填项，须取权威名录逐条核对【名录版本待核 #5】。
- 设计 PUE 及其算术支撑（年总电量 ÷ IT 电量，须给年加权负荷表，满载单点值不算）。
- 绿电比例证据链：物理结算电量、绿证张数、环境权益归属与注销安排，三分列。绿电占比超过 80% 的项目属于优先支持方向，具体适用条件、核算口径和兑现方式须按项目所在地及最新政策确认（总旁注 8）。
- 能耗数据：年综合能耗当量值 / 等价值（tce）、单位工业增加值能耗、能耗替代来源与年度。
- 分期项目：按累计规模判档（禁止报小建大），一期 / 整体两套口径必须冻结为唯一申报值。
- 广东项目另收：节能审查 + 碳排放评价材料清单（2026 年新办法口径，文号【待核 #3】）。
- 内蒙古 / 青海 / 重庆项目另收：2.3.1 矩阵十二字段对应书面材料，缺则【待核】，禁止用一地条款填另一地。

**红线 / 停机条件**

- **正式政策要求**：大型及以上项目未取得窗口指导肯定性结论，不推进备案、能评、网络接入。根据 320 号作此政策判断，原文页码【待核 #2】。
- **公司内部停机规则**：未过窗口，不得推进电力接入承诺；不得签署以「项目获批」为默认前提的商务条款。此两条是公司内部控制，不是全国统一法定门槛。
- **公司内部停机规则**：申报规模不唯一（整体 / 一期 / 机柜算术三口径并存）→ 先冻结唯一口径再谈。
- **正式政策要求 + 属地执行要求**：选址无法完成枢纽节点 / 集群起步区判定 → 不出任何规模承诺；属地书面名录未核前标【待核】。
- **正式政策要求**：绿电「拟签约」「争取」「承诺 100%」三类表述并存即视为证据链断裂，退回补正；不接受公司层面历史采购量顶项目级落实。
- **公司内部停机规则**：需求侧未形成「客户—服务地址—IT 功率—交付期」闭环的，规模必要性不成立；意向量不得表述为已锁定消纳量。

### 2.1 320 号框架

根据发改高技〔2025〕320 号已核公开原件：大型及以上数据中心（含智算）纳入窗口指导，不分投资主体。附件 1 原始分类为「大型及以上 / 中型 / 小型」，不以「超大 / 大 / 中小」改写。已核原件第 1、3、8、9 页可实引框架性条目；其余摘引页码【待核 #2】。

接单动作按三步，不跳步：

1. **定对象**：是否数据中心（含智算）。是则进入 320 号视野，不因投资主体、外资、央企身份豁免。
2. **定分档**：用 2.2 算术。IT 功率达到 7500kW（3000 标准架 × 2.5kW，原件第 8 页已核）即大型档起点，属「大型及以上」，必进窗口。中型、小型阈值未核前，不得自行划一条「中型就可避窗」的线。

### 2.2 规模分档与算术自查

政策原始分档只认三种：大型及以上 / 中型 / 小型。「超大型」若公司内部要单列，只作内部风险分级，不改写附件 1；公司是否单列及阈值【待核 #28】，须落公司风控 / 投资制度，无制度则保持【待核】。

**算术（只用于分档，不用于售卖）**

1. 机柜清单逐项：档位 i 的柜数 × 该档单柜功率（kW），相加得 IT kW。不得用「平均柜功率 × 宣称柜数」替代逐项相加。
2. 折合标准架数 = IT kW ÷ 2.5 kW。2.5 kW 不得与 ≥12 kW 高密口径混用。
3. IT kW ≥ 7500（即标准架 ≥ 3000）→ 大型及以上 → 窗口指导。低于该线的，仍须核中型 / 小型阈值及服务器采购金额维度【待核 #1】，未核前不宣称「肯定不进窗」。
4. 分期按累计规模判档，禁止报小建大。一期申报值、整体规划值、机柜算术值三口径必须冻结为唯一申报值，其余降为附件说明。

### 2.4 上架率与需求闭环

规模必要性不靠园区规划人数或「全国算力缺口」撑住，只靠四要件闭环：

| 要件 | 合格标准 | 不合格即停 |
|---|---|---|
| 客户 | 具名客户或已签意向的法律主体，能指向付款方 | 只有行业类型、无主体 |
| 服务地址 | 机房或交付节点可落图，与选址政策格一致 | 地址可改口、与申报地点不一致 |
| IT 功率 | 与 2.2 唯一申报口径一致，单位 kW / MW | 用 PFLOPS 反推定功率 |
| 交付期 | 年 / 季可核对，与电力接入周期对照 | 「尽快」「视审批」 |

1843 号、88 号起步区目标均写上架率不低于 65%。该数是集群起步区目标口径，已核官方 HTML；不得自动写成公司对客户的满租承诺，也不得用满租收入倒推上架率。意向量只可作附件，并标注法律性质，不得嵌入收入主表。

### 2.5 PUE

PUE 三分法，评审只认能说清工况的那一列：

| 类型 | 算法要点 | 可否单独报窗 |
|---|---|---|
| 设计值 | 设计工况下总电量 / IT 电量 | 须同时给年加权支撑 |
| 满载值 | 满载单点 | 不算，常见退回样式 |
| 年加权值 | 年总电量 ÷ 年 IT 电量，须附年加权负荷表 | 申报主口径 |

320 号项下「PUE 控制在 1.25 以内」的表述页码【待核 #2】，未核前不把 1.25 写成已核全国强制线。区域线只写在 2.3.1 对应列：内蒙古新建 1.2 以下（26 号转载，不得抄走）；青海大型及以上 1.2 以下（7 号，基地 / 该类项目口径）；重庆起步区目标 1.25 以内（88 号）。电费测算隐含 PUE 必须与设计 PUE 一致，成本表隐含 PUE=1.0 视为硬伤，见第 3 章。

### 2.6 绿电与能耗替代

八项分列，禁止混用：绿电交易、绿证、物理供电、绿电直连、自备新能源、源网荷储、绿电比例核算、环境权益归属。证据链只认三列并列：物理结算电量、绿证张数、环境权益归属与注销安排。

绿电占比超过 80%：属优先支持方向（总旁注 8），不是全国硬性已批待遇，不是认证，不是收益率。内蒙古 26 号「绿电比例不低于 80%」只适用于该意见覆盖的内蒙古项目，且须核兑现前提，不得写成公司项目一定可享受，不得抄到青海 / 重庆。青海 11 号「80% 以上绿电用能保障」是产业保障表述。重庆 26 号解读中的「超过 80%」是否强制，实施方案 PDF 未打开【待核】。

能耗替代须写来源与年度。公司历史绿电采购量不得顶本项目落实。当量值 / 等价值（tce）分列，对应 320 号能耗核算口径；柴发等非电品种是否计入见 3.7。

### 2.7 广东节能审查 + 碳排放评价

广东省固定资产投资项目节能审查和碳排放评价实施办法（2026-08，省发改委 + 省能源局联合印发，取代粤能规〔2023〕3 号）：数据中心（含智算）列重点领域，逐项审查 + 碳排放评价。文号、生效日、红头原件与实施细则【待核 #3】，未核前不引条文、不编审查时限。

### 2.8 窗口指导评审实务

附件 2 申请书八部分逐块核对。建设地点块必须出现枢纽 / 集群起步区判定，不能只写门牌。规模块必须与 2.2 唯一申报值一致。能效块必须有年加权 PUE，不能只报满载。绿电块必须三分列，不能只写「争取 100%」。需求块必须有 2.4 四要件。

常见高风险退回原因（来源脚注：内部窗口指导复盘材料，不展开、不写项目名）：

1. 整体 / 一期 / 机柜算术三口径并存，申报规模不唯一。

5. 需求侧只有意向，没有客户—地址—功率—交付期闭环。
6. 分期报小建大，累计规模未判档。
7. 把公司内部控制或地方奖励写成已获批条件。

## 3 能源与电力 ★

**结论句**：能源电力是公司在算力赛道的本位能力，也是本指引里唯一可以「以我为主」谈的板块；谈的顺序是先源网荷储整体方案、再绿电直连路径（650 / 688 号框架）、再责任界面与计量结算，任何环节都不得把政策方向或测算电价写成电价承诺。绿电交易、绿证、物理供电、绿电直连、自备新能源、源网荷储、绿电比例核算、环境权益归属，八项分列，禁止混用。

**要问的数 / 要收材料**

- 负荷侧：IT 功率、PUE、年用电量（IT 电量与辅助电量分列）、负荷曲线 / 负荷率、柴发等非电能源品种是否计入能耗边界。
- 电源侧：变电容量、接入电压等级、供电可靠性要求（N+1 / 2N）、是否需专线 / 专变。
- 绿电路径：拟采用绿电直连、绿电交易还是绿证采购；对应的物理结算电量、计量点位置、权益归属主体。
- 储能与源网荷储：是否配储、容量与用途（调峰 / 备电 / 需量管理），投资归属在公司侧还是客户侧。
- 结算：电费单价的构成（目录电价 / 市场化交易价 / 输配电价 / 基金附加），电费由谁向电网结算、谁向客户转售或代收。
- 责任界面：产权分界点、运维分界点、计量点三点是否重合，不重合处逐一列明。
- 3.8 证明包七项：当地目录电价、交易价构成、输配电价、基本电费、偏差考核、绿电环境权益归属、电网接入意见；缺则【待核】。

**红线 / 停机条件**

- **公司内部停机规则**：电价、绿电比例、收益率均不得以「政策支持」名义写成承诺值；测算电价须标注假设条件与对照来源（外地项目对照价不得直接搬用，适用性未论证即标【待核 #12】）。
- **正式政策要求**：绿电直连方案须以 650 / 688 号文件框架为准，条文原文与实施细则【待核 #4】前只写方向不写门槛。
- **属地执行要求**：绿电交易 / 绿证 / 直连 / 源网荷储的可执行性，以省级衔接规则 + 电网书面确认为准，口头政策宣介不得入测算承诺栏。
- 「不投服务器」不等于 IT 电量可从能耗边界剔除；反之，IT 电量计入也不等于服务器成为公司资产——能耗边界与资产边界分开写。
- 电费测算隐含 PUE 必须与设计 PUE 一致（评审已出现成本表隐含 PUE=1.0 的硬伤样式，列入自查）。
- **公司内部停机规则**：计量点、结算主体未落图前，不签能源管理 / 合同能源管理类协议。

### 3.0 电力优先排序

结构参考电力优先开发时序（对标摘要：先锁电力容量与接入 → 再定设计 → 审批 → 建造 → 采购 → 调试；机构 / 版本【待核】，只吸收顺序，不吸收未核原文）。本指引固化为：

| 顺序 | 环节 | 未完成时不得排期的后续 |
|---|---|---|
| 1 | 锁电力容量与接入路径（含电网书面意见） | 不得定最终机电方案、不得报可研电价承诺 |
| 2 | 定设计（与唯一 IT 功率、PUE 一致） | 不得采购长周期电气设备冒充已接入 |
| 3 | 审批（窗口 / 能评 / 属地，按第 2 章） | 不得以「待批」签供电承诺 |
| 4 | 建造 | 不得提前报竣工用电 |
| 5 | 采购 | 服务器 / 卡采购不倒逼未锁电力 |
| 6 | 调试与受电 | 计量点未齐不进入商业运营 |

电力未锁，后续环节一律不排期。此条是公司内部工作顺序，不写成国家法定时序。

能源口接单首日只做三件事：把 IT 功率与 2.2 唯一口径对齐；向电网或业主要接入意见的书面状态（已有 / 在办 / 未启动）；把拟谈的绿电路径勾成八项中的哪几项。三件事做完之前，不报电价区间，不排设计审查会。

**电力未锁自查（公司内部停机规则，不是法定时序）**

| 检查项 | 合格 | 停机 |
|---|---|---|
| IT 功率与申报唯一口径 | 同一 kW / MW | 与机柜算术或一期口径并存 |
| 电网书面接入意见 | 有容量、电压、周期、界面四要素，或明确「尚未出具」 | 用园区宣传或外地项目参数顶替 |
| 绿电路径 | 八项已勾选采用 / 不采用 / 待核 | 只写「绿电方案」一词 |
| 隐含 PUE | 与设计 PUE 同一数 | 成本表隐含 1.0 或另套宣传值 |

### 3.0.1 能源属地分层提纲

五层分开写，禁止用上一层的方向顶下一层的承诺：

1. **国家政策框架**：320 号能耗与绿电路径；650 / 688 号直连（原文【待核 #4】）；全国绿电交易 / 绿证规则（环境权益见发改能源〔2024〕1123 号）。绿电占比超过 80% 在本层只作优先支持方向。
2. **省级衔接规则**：交易品种、直连实施细则、峰谷与偏差。内蒙古 / 青海 / 重庆已见文号见 3.8 与 8.4.1，未齐项保持【待核 #22】。

5. **可纳入测算与不得纳入承诺**：测算可列假设；承诺仅限已取得书面文件的量价与期限。

### 3.1 源网荷储一体化方案框架

公司在本板块谈方案，先问适配、再谈投资归属。适配判定至少六问：负荷是否稳定到可「以荷定源」；电源是否可物理或交易对应；电网是否接受一体化或直连接入；储能用途是调峰、备电还是需量管理；计量点能否把源、网、荷、储分开结算；环境权益归谁注销。

算电协同只作方向引用：国家数据基础设施建设指引（2024）与公开电碳算报道，原文条款【待核 #15】，不作门槛。公司能力清单对标第 4 章已有形态（供电 + 绿电、底座、储能、绿证碳、合同能源），不编新产品名。

三地公开方向已写入 2.3.1 字段 6，不在此重复当门槛。青海 7 号第 1、7 条与 11 号第 6 条写源网荷储 / 直供电试点，是省级方向；项目能不能做，仍看省级衔接 + 电网书面意见。内蒙古 26 号鼓励多年度交易、直供与构网型储能，同样只是该地方向，不抄到青海 / 重庆，不写成公司可享受。

### 3.2 绿电直连（650 / 688 号）

绿电直连与绿电交易、绿证采购不是同一条路径。未核 650 / 688 号原文与省级细则前【待核 #4】，本指引只写方向：

- 适用情形：负荷与新能源场站之间是否具备直连的物理与调度条件——以文件框架和电网意见为准，不在此编电压或距离门槛。
- 接入形态：专线、内部电网或文件允许的其他形态，须在电网意见中写明，口头「可以直供」无效。
- 与交易 / 绿证的关系：直连解决的是物理供电路径；交易解决的是市场化电能量；绿证解决的是环境权益凭证。三者可以并存，但电量不得重复计算进绿电比例。
- 内蒙古转载可见内能源新能字〔2025〕361 号等，官方原页【待核】；青海、重庆省级衔接正式文本【待核 #22】。未核前不把一地转载细则套到另外两地。

路径选择只作内部判断，不代替文件：有物理直连条件且电网书面接受 → 按 650 / 688 号框架做方案，细则未核前不写门槛；无直连条件 → 绿电交易与绿证分列；只有宣传「100% 绿电」而无计量点 → 证据链断裂，退回 2.6。三选一或组合都可以，但同一兆瓦时不得同时充当直连电量、交易电量和绿证核减的重复分子。

## 4 可建 / 可售清单 ★

**结论句**：本章只收产业里已有的业务形态及其红线，供业务人员对号入座；公司自有产品包、标准报价、客户名册一概不编——缺什么标【待核】进第 8 章，由后续版本经审批后补入。

**要问的数 / 要收材料**（按形态逐项收）

- 机柜类：机柜功率档（标准 2.5kW 折档口径 / 高密 ≥12kW 口径分列）、上架率承诺、SLA 等级。
- 算力租赁类：整机 / 裸金属 / 虚拟化层级，计价单位（台·月 / 卡·月）与市场参考区间【待核 #8】。
- 卡时 / 机时类：卡型、单卡算力（FP16 分列，不与 IT MW 互推）、计费粒度；若涉卡型峰值 / 内存对比，按总旁注 7，不可对等。
- 调度 / 绿电碳类：算力调度服务的标的与计量方式、绿电绿证代理、碳核算 / 碳资产服务的交付物。
- 合同能源管理类：节能量基准、分享比例、测量验证方案。

**红线 / 停机条件**

- **禁止**编造公司产品包名称、标准价目表、已锁订单或客户名册；对外只用总旁注 6 的三短语定位。（公司内部停机规则）
- 满租 / 满载收入测算必须标注单价来源（现估 / 意向 / 合同三分），无敏感性分析的满租测算不得进决策材料。
- 意向订单（含头部客户意向）不得嵌入付款时序、收入主表，只能作附件并标注法律性质。
- 卡时 / 机时报价合计不得写成合同额；算力（PFLOPS）与功率（MW）禁止互相折算充数。
- 「以卡抵资」「Token 分成」等无约束性安排降级附注，不进主逻辑。

### 4.2 机柜与托管

批发型按大柜位 / 大电力块签约，零售型按单柜或机位签约。租约核心要件（结构参考供电 / 租约 / 融资三面，原文【待核】）：

1. 电力容量承诺与 2.2、3.3 同一口径。
2. 电价传导：目录、交易、输配、基本电费如何传导或包干；包干必须写死假设 PUE。
3. SLA：供电、制冷、可用性指标与免责。
4. 期限与退出：到期、违约、政策变化三情形，与 6.7 对齐。
5. 上架率：承诺值须有需求闭环支撑；不得用集群起步区 65% 目标冒充租约满租承诺。

标准架 2.5 kW 只用于政策分档；售卖高密柜用 ≥12 kW 档本身。两套数在合同附件分列。

### 4.3 算力租赁

先定层级：整机、裸金属、虚拟化，三者计价与运维界面不同。市场参考区间【待核 #8】，未核前测算标「初步测算 / 现估」，不得写入承诺栏。残值风险单独列：卡或服务器残值假设变更，不得靠调电价或调绿电比例回填。是否自持运营【待核 #7】未写死前，不把本形态写成公司标准业务。

层级差异只写界面，不写未核单价：

| 层级 | 交付界面 | 运维通常在谁 | 残值主要落在谁 | 计价单位 |
|---|---|---|---|---|
| 整机 | 可用整机，含或不含维保须写明 | 按合同 | 持有资产方 | 台·月 |
| 裸金属 | 物理机独占 | 按合同 | 持有资产方 | 台·月 / 卡·月 |
| 虚拟化 | 切片资源 | 通常服务方 | 视是否自持底层 | 规格·月 |

满租 / 满载收入测算必须三分单价来源：现估、意向、合同。无敏感性分析（至少负荷率、单价、电价三条）的满租测算不进决策材料。意向订单不得嵌入付款时序。

### 4.4 卡时 / 机时

### 4.5 调度与算网服务

产业现状：枢纽集群政策普遍写调度、互联、跨区域协同（见 2.3.1 字段 8），这是公开方向，不是公司已获准入。公司可介入点【待核 #7】：在角色未写死前，只允许谈「可对标的服务界面」（计量方式、结算标的、与电力协同的数据接口），不允许谈「公司调度平台已覆盖某省」。互联具体要求【待核 #14】。

内蒙古 26 号接入「多云」调度平台的奖励条款，须核有效期与兑现前提，不得写成已获资格，不得抄到青海 / 重庆。重庆算力券、青海算力券激励各用各的文件，申领主体与额度不得串用，也不得写成公司已获资格（见 2.3.1 字段 9、待核 #27）。

调度服务可谈的界面仅限：标的（调度的是算力、带宽还是电力协同数据）、计量方式、与客户或平台的结算货币、退出时数据与账号移交。不可谈的界面：未核的互联强制指标【待核 #14】、未写死的公司平台覆盖范围、把地方奖励当销售卖点写进主合同。

### 4.6 绿电、绿证与碳服务

## 5 建设分类

**结论句**：建设形态按新建 / 改造 / 边缘三分；政策分档对齐 320 号附件 1（大型及以上 / 中型 / 小型），不以「超大 / 大 / 中小」改写原始分类。「超大型」若需单列，只作公司内部风险分级【待核 #28】。本章只给归类差异，技术方案不在本指引。

**要问的数 / 要收材料**

- 新建 / 改造：存量建筑与用地性质、既有变电可利用容量。
- 政策分档：与第 2 章同一套 IT kW / 标准架口径；中型、小型及采购金额维【待核 #1】。
- 边缘：单点功率及与中心节点关系。公司内部是否单列「超大型」【待核 #28，不改写 320 号】。

**红线 / 停机条件**

- 改造不得默认沿用原批复能耗覆盖新增负荷；用地待调整先停。（正式政策要求 + 属地执行要求）
- 分期按累计规模判档，禁止报小建大（同第 2 章）。（正式政策要求）

**展开**（从薄，不扩方案）

### 5.1 新建 / 改造 / 边缘判定

可参考公开建设白皮书 / 上海导则分类，不抄产品。上海导则正文指标【待核 #6】。

### 5.3 改造特有核查

用地性质与规划是否覆盖数据中心用途；结构荷载是否支持高密柜（技术结论留给设计，本指引只要求「有书面结论」）；既有能评 / 能耗指标是否覆盖新增 IT 功率，不覆盖则按新增负荷重新走审查，不得默认沿用。既有变电可利用容量以电网意见为准，不编参数。

## 6 运营、安全与交接 ★

**结论句**：项目能不能「交出去」取决于四件事在建设期就写清：调度与运行责任、计量点与结算路径、协议清单齐套、退出与违约安排；交接不是竣工移交单，而是一套边界文件包，缺一项就意味着公司背上说不清的长期义务。

**要问的数 / 要收材料**

- 运行责任矩阵：动力 / 制冷 / IT / 网络四层各自的运行方、值守方、故障响应 SLA。
- 计量点清单：每个计量点的位置、归属、抄表与结算周期，与第 3 章责任界面三点图对齐。
- 协议清单（齐套核对单）：供电协议、绿电 / 绿证协议、运维协议、托管 / 租赁合同、保险、（如有 SPV）股东协议与章程；SPV 类合同须单列电力与能耗条款、退出条款。
- 担保与增信排查：安慰函、差额补足、回购承诺等实质担保条款逐条列出——「不默认连带」措辞歧义即视为未排除。
- 安全界面：消防、柴发油罐等危险源的责任归属与应急联动；周边敏感点（学校 / 居住区）距离与结论。
- 退出安排：合同到期 / 违约 / 政策变化三情形下的资产处置、数据迁移、人员与备件移交。

**红线 / 停机条件**

- **公司内部停机规则**：SPV 结构下法律意见（一致行动人 / 代持 / 关联交易审批路径）未出具，不得办理股权受让或对外签署治理承诺。
- **公司内部停机规则**：金租、融资方要求的任何形式实质担保未经授权审批，不得以「不默认连带」类模糊措辞带过。
- 计量点与结算主体不闭环，不进入商业运营；交接文件包不齐套，不办移交。
- 运营期收入类条款（闭口费、维保费）区间过宽（如上下限差超两成）且倒算公式不闭合的，退回重谈。

**展开**

交接从建设期第一份供电或合营协议开始收，不接到竣工再补。立项通过后指定交付经理；交付经理对 6.8 目录负责，市场口与能源口对各自口径冻结页负责。文件包不齐套，竣工验收可以走工程口，但业务交接不办、商业运营不启。
