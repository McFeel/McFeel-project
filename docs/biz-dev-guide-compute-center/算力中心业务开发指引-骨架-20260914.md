## 2 政策与布局红线（6–9 页）★厚写

**结论句**：现行监管的第一道闸不是能评而是「政策位置」——发改高技〔2025〕320 号将大型及以上算力中心全部纳入窗口指导（不分投资主体，外资不豁免），且国家枢纽节点外原则上不得新建大型及超大型算力中心；未过窗口，备案、节能审查、网络接入均无从谈起。业务人员接单第一件事是核规模分档与选址落在哪个政策格子，而不是先谈电价。

**要问的数 / 要收材料**
- 项目 IT 总功率（kW / MW）与机柜清单（数量 × 单柜功率，逐项相加复核）；折合标准架数 = IT kW ÷ 2.5kW，仅用于分档。
- 分档判定：≥7500kW（3000 标准架）即大型档起点，必进窗口指导；其余分档阈值【待核】。
- 选址是否位于国家枢纽节点 / 数据中心集群起步区——申报必填项，须取权威名录逐条核对【名录版本待核】。
- 设计 PUE 及其算术支撑（年总电量 ÷ IT 电量，须给年加权负荷表，满载单点值不算）。
- 绿电比例证据链：物理结算电量、绿证张数、环境权益归属与注销安排，三分列（320 号项下「绿电超 80%」是优先支持门槛，不是强制红线，也不是已实现结论）。
- 能耗数据：年综合能耗当量值 / 等价值（tce）、单位工业增加值能耗、能耗替代来源与年度。
- 分期项目：按累计规模判档（禁止报小建大），一期 / 整体两套口径必须冻结为唯一申报值。
- 广东项目另收：节能审查 + 碳排放评价材料清单（2026 年新办法口径，文号【待核】）。

**红线 / 停机条件**
- **停机**：大型及以上项目未取得窗口指导肯定性结论，一律不推进备案、能评、电力接入承诺，不签任何以「项目获批」为默认前提的商务条款。
- **停机**：申报规模不唯一（整体 / 一期 / 机柜算术三口径并存）→ 先冻结唯一口径再谈。
- **停机**：选址无法完成枢纽节点 / 集群起步区判定 → 不出任何规模承诺。
- 绿电「拟签约」「争取」「承诺 100%」三类表述并存即视为证据链断裂，退回补正；不接受公司层面历史采购量顶项目级落实。
- 需求侧未形成「客户—服务地址—IT 功率—交付期」闭环的，规模必要性不成立；意向量不得表述为已锁定消纳量。
- PUE 引用值须注明负载工况；320 号项下 PUE 控制线（1.25 以内的表述）页码【待核】，未核前按「已核原件摘要引用」口径旁注。
- 政策方向不得写成强制门槛、补贴、认证或收益率承诺。

**提纲占位**
- 2.1 320 号框架：适用范围、分类处理、窗口指导流程；附件 1 规模分档、附件 2 申请书要求（知识库已核原件 CKZD.pdf，第 1、3、8、9 页条目实引；其余摘引标注）
- 2.2 规模分档与算术自查表（机柜逐项相加 → IT kW → ÷2.5kW 折档；示例算式留空位；标准架 2.5kW 与高密 ≥12kW 口径分列声明）
- 2.3 布局与互联红线：枢纽节点 / 集群起步区判定操作步骤 + 名录索引【待核】；算力互联互通行动计划（工信部 2025）与国家数据基础设施建设指引（发改委 / 数据局 / 工信部 2024）项下的互联、标识、调度衔接要求【原文条款待核】
- 2.4 上架率与需求闭环：客户—地址—MW—交付期四要件核对单
- 2.5 PUE：设计值 / 满载值 / 年加权值三分法，评审常见退回样式
- 2.6 绿电与能耗替代：物理电量、绿证、环境权益三分列 + 替代来源核验
- 2.7 广东节能审查 + 碳排放评价（2026-08 办法，省发改 + 能源局，取代粤能规〔2023〕3 号；数据中心含智算为重点领域，逐项审查；细则【待核】）与两高关联审查
- 2.8 窗口指导评审实务：320 号附件 2 八部分申请书材料清单逐块核对法、常见高风险退回原因清单（来源脚注：CKZD 腾龙 / 电信窗口样本，内部材料，不展开）

## 3 能源与电力（6–9 页）★厚写

**结论句**：能源电力是公司在算力赛道的本位能力，也是本指引里唯一可以「以我为主」谈的板块；谈的顺序是先源网荷储整体方案、再绿电直连路径（650 / 688 号框架）、再责任界面与计量结算，任何环节都不得把政策方向或测算电价写成电价承诺。

**要问的数 / 要收材料**
- 负荷侧：IT 功率、PUE、年用电量（IT 电量与辅助电量分列）、负荷曲线 / 负荷率、柴发等非电能源品种是否计入能耗边界。
- 电源侧：变电容量、接入电压等级、供电可靠性要求（N+1 / 2N）、是否需专线 / 专变。
- 绿电路径：拟采用绿电直连、绿电交易还是绿证采购；对应的物理结算电量、计量点位置、权益归属主体。
- 储能与源网荷储：是否配储、容量与用途（调峰 / 备电 / 需量管理），投资归属在公司侧还是客户侧。
- 结算：电费单价的构成（目录电价 / 市场化交易价 / 输配电价 / 基金附加），电费由谁向电网结算、谁向客户转售或代收。
- 责任界面：产权分界点、运维分界点、计量点三点是否重合，不重合处逐一列明。

**红线 / 停机条件**
- 电价、绿电比例、收益率均不得以「政策支持」名义写成承诺值；测算电价须标注假设条件与对照来源（外地项目对照价不得直接搬用，适用性未论证即标【待核】）。
- 绿电直连方案须以 650 / 688 号文件框架为准，条文原文与实施细则【待核】前只写方向不写门槛。
- 「不投服务器」不等于 IT 电量可从能耗边界剔除；反之，IT 电量计入也不等于服务器成为公司资产——能耗边界与资产边界分开写。
- 电费测算隐含 PUE 必须与设计 PUE 一致（评审已出现成本表隐含 PUE=1.0 的硬伤样式，列入自查）。
- 计量点、结算主体未落图前，不签能源管理 / 合同能源管理类协议。

**提纲占位**
- 3.0 电力优先排序声明（对齐 Coloprice 开发时序：先锁电力容量与接入 → 再定设计 → 审批 → 建造 → 采购 → 调试；电力未锁前后续环节不排期）
- 3.1 源网荷储一体化方案框架（公司能力清单 + 项目适配判定；算电协同方向引国家数据基础设施建设指引（2024）与电碳算公开报道，方向性引用不作门槛【原文待核】）
- 3.2 绿电直连（650 / 688 号）：适用情形、接入形态、与绿电交易 / 绿证的关系【条文细则待核】
- 3.3 供配电方案要件：容量、等级、可靠性、专线专变的商务归属
- 3.4 储能配置与投资归属谈判要点
- 3.5 责任界面三点图（产权 / 运维 / 计量）+ 标准分界描述模板
- 3.6 计量与结算：电费构成分解表、代收 / 转售合规要点
- 3.7 能耗边界声明模板（电 + 柴油等非电品种；对应 320 号能耗核算口径）
- 3.8 电价与收益表述纪律（假设 / 对照 / 承诺三分法）

## 5 建设分类（2–3 页，从薄）

**结论句**：建设形态按新建 / 改造 / 边缘三分，规模按超大 / 大 / 中小三档（分档阈值以 320 号附件 1 已核条目为准，其余【待核】）；本章只给归类和差异要点，深度技术方案不在本指引内。

**要问的数 / 要收材料**
- 新建 / 改造判定：存量建筑与用地性质、既有变电容量可利用量。
- 规模档：IT kW 与折合标准架数（分档专用）。

## 6 运营、安全与交接（5–7 页）★厚写

**结论句**：项目能不能「交出去」取决于四件事在建设期就写清：调度与运行责任、计量点与结算路径、协议清单齐套、退出与违约安排；交接不是竣工移交单，而是一套边界文件包，缺一项就意味着公司背上说不清的长期义务。

**要问的数 / 要收材料**
- 运行责任矩阵：动力 / 制冷 / IT / 网络四层各自的运行方、值守方、故障响应 SLA。
- 计量点清单：每个计量点的位置、归属、抄表与结算周期，与第 3 章责任界面三点图对齐。
- 协议清单（齐套核对单）：供电协议、绿电 / 绿证协议、运维协议、托管 / 租赁合同、保险、（如有 SPV）股东协议与章程；SPV 类合同须单列电力与能耗条款、退出条款（对齐建纬投建营体裁）。
- 担保与增信排查：安慰函、差额补足、回购承诺等实质担保条款逐条列出——「不默认连带」措辞歧义即视为未排除（内部评审教训）。
- 安全界面：消防、柴发油罐等危险源的责任归属与应急联动；周边敏感点（学校 / 居住区）距离与结论。
- 退出安排：合同到期 / 违约 / 政策变化三情形下的资产处置、数据迁移、人员与备件移交。

**红线 / 停机条件**
- **停机**：SPV 结构下法律意见（一致行动人 / 代持 / 关联交易审批路径）未出具，不得办理股权受让或对外签署治理承诺。
- **停机**：金租、融资方要求的任何形式实质担保未经授权审批，不得以「不默认连带」类模糊措辞带过。
- 计量点与结算主体不闭环，不进入商业运营；交接文件包不齐套，不办移交。
- 运营期收入类条款（闭口费、维保费）区间过宽（如上下限差超两成）且倒算公式不闭合的，退回重谈。

**提纲占位**
- 6.1 运行责任矩阵模板（四层 × 三方）
- 6.2 计量与结算交接：计量点台账 + 结算路径图占位
- 6.3 协议齐套清单（分自建 / 合营 / 服务三版）
- 6.4 担保与增信负面清单（安慰函 / 差补 / 回购逐条排查）
- 6.5 安全界面与应急：危险源、敏感点、消防联动责任表
- 6.6 SPV 治理与关联交易：审批层级、定价方法、回避表决占位（法律意见前置）
- 6.7 退出与终止：三情形处置预案要件
