## 2 政策与布局红线（8–11 页）★厚写

**结论句**：现行监管的第一道闸不是能评而是「政策位置」——根据发改高技〔2025〕320 号，大型及以上算力中心全部纳入窗口指导（不分投资主体，外资不豁免）；国家枢纽节点外原则上不得新建大型及以上算力中心（「超大型」是否单列以附件 1 原文为准，页码【待核】）。未过窗口，备案、节能审查、网络接入均无从谈起——此条为基于 320 号的政策判断。业务人员接单第一件事是核规模分档与选址落在哪个政策格子，而不是先谈电价。内蒙古 / 青海 / 重庆的属地路径见 2.3.1，三地条件不得互抄。

**要问的数 / 要收材料**
- 项目 IT 总功率（kW / MW）与机柜清单（数量 × 单柜功率，逐项相加复核）；折合标准架数 = IT kW ÷ 2.5kW，仅用于分档。
- 政策分档判定：≥7500kW（3000 标准架）即大型档起点，属「大型及以上」，必进窗口指导；中型、小型阈值及服务器采购金额判定维度【待核】。
- 选址是否位于国家枢纽节点 / 数据中心集群起步区——申报必填项，须取权威名录逐条核对【名录版本待核】。
- 设计 PUE 及其算术支撑（年总电量 ÷ IT 电量，须给年加权负荷表，满载单点值不算）。
- 绿电比例证据链：物理结算电量、绿证张数、环境权益归属与注销安排，三分列。绿电占比超过 80% 的项目属于优先支持方向，具体适用条件、核算口径和兑现方式须按项目所在地及最新政策确认（总旁注 8）。
- 能耗数据：年综合能耗当量值 / 等价值（tce）、单位工业增加值能耗、能耗替代来源与年度。
- 分期项目：按累计规模判档（禁止报小建大），一期 / 整体两套口径必须冻结为唯一申报值。
- 广东项目另收：节能审查 + 碳排放评价材料清单（2026 年新办法口径，文号【待核】）。
- 内蒙古 / 青海 / 重庆项目另收：2.3.1 矩阵十二字段对应书面材料，缺则【待核】，禁止用一地条款填另一地。

**红线 / 停机条件**
- **正式政策要求**：大型及以上项目未取得窗口指导肯定性结论，不推进备案、能评、网络接入。根据 320 号作此政策判断，原文页码【待核】。
- **公司内部停机规则**：未过窗口，不得推进电力接入承诺；不得签署以「项目获批」为默认前提的商务条款。此两条是公司内部控制，不是全国统一法定门槛。
- **公司内部停机规则**：申报规模不唯一（整体 / 一期 / 机柜算术三口径并存）→ 先冻结唯一口径再谈。
- **正式政策要求 + 属地执行要求**：选址无法完成枢纽节点 / 集群起步区判定 → 不出任何规模承诺；属地书面名录未核前标【待核】。
- **正式政策要求**：绿电「拟签约」「争取」「承诺 100%」三类表述并存即视为证据链断裂，退回补正；不接受公司层面历史采购量顶项目级落实。
- **公司内部停机规则**：需求侧未形成「客户—服务地址—IT 功率—交付期」闭环的，规模必要性不成立；意向量不得表述为已锁定消纳量。

## 3 能源与电力（7–9 页）★厚写

**结论句**：能源电力是公司在算力赛道的本位能力，也是本指引里唯一可以「以我为主」谈的板块；谈的顺序是先源网荷储整体方案、再绿电直连路径（650 / 688 号框架）、再责任界面与计量结算，任何环节都不得把政策方向或测算电价写成电价承诺。绿电交易、绿证、物理供电、绿电直连、自备新能源、源网荷储、绿电比例核算、环境权益归属，八项分列，禁止混用。

## 6 运营、安全与交接（5–7 页）★厚写

**结论句**：项目能不能「交出去」取决于四件事在建设期就写清：调度与运行责任、计量点与结算路径、协议清单齐套、退出与违约安排；交接不是竣工移交单，而是一套边界文件包，缺一项就意味着公司背上说不清的长期义务。

**要问的数 / 要收材料**
- 运行责任矩阵：动力 / 制冷 / IT / 网络四层各自的运行方、值守方、故障响应 SLA。
- 计量点清单：每个计量点的位置、归属、抄表与结算周期，与第 3 章责任界面三点图对齐。
- 协议清单（齐套核对单）：供电协议、绿电 / 绿证协议、运维协议、托管 / 租赁合同、保险、（如有 SPV）股东协议与章程；SPV 类合同须单列电力与能耗条款、退出条款。
- 担保与增信排查：安慰函、差额补足、回购承诺等实质担保条款逐条列出——「不默认连带」措辞歧义即视为未排除。
- 安全界面：消防、柴发油罐等危险源的责任归属与应急联动；周边敏感点（学校 / 居住区）距离与结论。
- 退出安排：合同到期 / 违约 / 政策变化三情形下的资产处置、数据迁移、人员与备件移交。

**红线 / 停机条件**
- **公司内部停机规则**：SPV 结构下法律意见（一致行动人 / 代持 / 关联交易审批路径）未出具，不得办理股权受让或对外签署治理承诺。
- **公司内部停机规则**：金租、融资方要求的任何形式实质担保未经授权审批，不得以「不默认连带」类模糊措辞带过。
- 计量点与结算主体不闭环，不进入商业运营；交接文件包不齐套，不办移交。
- 运营期收入类条款（闭口费、维保费）区间过宽（如上下限差超两成）且倒算公式不闭合的，退回重谈。
