## 四、脚本用法与安全保证

`build_merged_book.py`（仅依赖 python-docx 与 Python 标准库）：

```bash
python3 build_merged_book.py 源书稿.docx --output 融合后书稿.docx
python3 build_merged_book.py 源书稿.docx --output 融合后书稿.docx --annex 第三篇附-新产品发布融合.md
python3 build_merged_book.py 源书稿.docx --dry-run   # 仅打印将替换的块，不写文件
```

- 输入文件只读打开，绝不修改或覆盖；脚本运行前后自动校验源文件 SHA-256 一致。
- `--output` 与输入路径相同时拒绝执行；输出文件已存在时拒绝覆盖（除非显式 `--force`）。
- 找不到"第三篇附／产品介绍板块／新产品发布系列"占位块时，脚本报错退出并列出已检索的特征，不产出任何文件。
- 替换边界：自占位块标题起，至下一个同级或更高级标题（或"第×篇／附录×"）止。
