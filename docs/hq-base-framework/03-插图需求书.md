# 插图需求书（Word 内插图，共 12 张）

**文件性质**：内部工作稿。本需求书列出《南网总部基地建设框架方案》Word 文稿的全部插图规格。插图是**进 Word 正文的图**（矢量图/高分辨率位图，随文排版），不是独立 HTML 站、不是大屏演示。

**通用规格**：

- 尺寸：随文通栏（约 15 cm 宽）为主，F2/F3/F11 可整页横排；分辨率不低于 300 dpi 或矢量；
- 风格：汇报稿风格——白底、南网色系（蓝绿为主）、中文标注、无英文装饰词；一图一个主张，图内文字能独立读懂，不依赖正文；
- 数据纪律：图中出现的数字一律带证据标注（角标或图注），口述/宣称数据在图注写明"未经核证，量级参照"；无数据的图不硬造数字；
- 编号与引用：图号 F1–F12 与《02-报告大纲》各章对应，制作后按 Word 章节重编"图 x-y"。
