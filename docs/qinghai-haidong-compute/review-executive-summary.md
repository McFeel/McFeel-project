## 关键阻塞项（5 项严重问题）

1. **一致行动人/关联交易**——法律意见未委托或未出具，"我司不控股"的表述缺乏法律基础。若被认定一致行动人，整套方案需要推倒重来。
2. **金租连带**——"不默认连带"措辞歧义，无法排除安慰函、差额补足等实质担保，可能突破 7500 万投资边界。
3. **代持风险**——联合体仅出 800 万却持 80% 股权，南网投 7500 万但不登记控股，权属隔离措施未说明。
4. **图 1–4 全部缺失**——股权结构图、利益传导图、支付瀑布图、付款时序图均无，审批者无法直观核验方案逻辑。
5. **关联交易审批路径空白**——仅一句"按关联交易审批执行"，未说明层级、定价方法和回避表决安排。

## 需重点补充的数据/文件（10 项重要问题，节选）

- 闭口费 1500–1875 万/年区间过宽（差 25%），倒算公式未闭合，维保 441.6 万/年是否包含未定。
- TABLE 3 五类设备映射全部"暂定"，6150→7500 调价明细缺失。
- 满租 38400 万/年基于"现估 25 万/台/月"，非合同价，无敏感性分析。
- 阿里意向已正确标注"不是已锁订单"，但仍嵌入付款时序表，应分离。
- 股权叙述"原股东合计≤20%"与"恒芯留股≤20%"口径不一致。

- 贷款 1.2 亿无银行授信确认，"先付土地"合规性待核。
