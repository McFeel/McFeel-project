# 申报单位组织管理与保障措施

项目编号：NWNY-2026-RD19

---

## 一、组织管理方式

本项目由南方电网综合能源（广东）有限公司（以下简称"广东公司"）作为申报及承担执行单位，南方电网综合能源股份有限公司为简表承担单位及任务书抬头单位。项目设课题负责人1名，由广东公司总经理柯文彬（高级经济师）担任，全面统筹项目技术路线与资源调配；王天智（高级工程师）负责项目整体推进实施；董福海（高级工程师）担任项目总指导，把控项目整体质量与方向。

项目下设4个课题、9项任务，采取"课题负责人统筹—骨干分线推进—技术支持协同"的组织架构。蔡志权负责把控课题整体方向与项目方法研究，李春龙负责课题技术指导，二者协同确保各课题研究方向与技术路径的科学性。晋智红、王建宁、魏飞强、骆耀科等承担成果转化协调跟进工作，确保研究成果向标准化产品和示范应用有效转化；欧丰华、钟东长、冯文汉、邹世明、王春磊等提供项目技术支持。

## 二、协调机制

项目实施期间安排启动、中期、验收三次专家咨询，每次邀请7位专家进行半天评审，及时检验研究进展、审查交付成果质量、提出改进建议，形成"外部专家咨询+内部技术协调"双轮驱动的质量保障机制。

项目按分年里程碑组织实施与考核：第二年度重点考核课题1至课题3的机理模型研究进展及阶段性知识产权成果（研究报告、专利、论文）；第三年度重点考核标准化平台研发、不少于3家规上工业企业示范接入与试点运行，以及结题验收材料完整性。各阶段节点明确，以考核驱动执行。

## 三、保障措施

**经费保障：** 项目总经费500万元，其中成本性费用400万元、资本性支出100万元，涵盖人工、测试化验、专家咨询、设备购置与租赁等各项支出，按分年预算与里程碑挂钩，保障资金按需到位。

**采购保障：** 项目启动阶段（2026年9至10月）即完成服务采购与招标工作，为后续课题研究和平台开发提供必要的技术服务与设备资源支撑。

**知识产权保障：** 项目规划产出发明专利3项、软件著作权1项、核心期刊或三大检索论文2篇，分阶段申报与交付，确保研究成果的知识产权保护。

**质量保障：** 标准化平台须具备CNAS/CMA资质，并提交第三方测试报告，确保平台的可靠性与权威性。示范应用以不少于3家规上工业企业为试点，覆盖公共机构、规上工业及制造园区场景，验证平台的可复制性与推广价值。
