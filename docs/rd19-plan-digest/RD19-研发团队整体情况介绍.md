# 研发团队整体情况介绍

项目编号：NWNY-2026-RD19

---

## 一、团队概况

本项目研发团队依托南方电网综合能源（广东）有限公司（以下简称"广东公司"，简表承担单位为南方电网综合能源股份有限公司）组建，现有成员14人，全部来自广东公司。团队以综合能源领域的技术研发与成果转化为核心定位，人员结构涵盖高级职称4人（高级经济师1人、高级工程师3人）、中级工程师9人、电力工程师1人，平均年龄约39岁，兼具管理决策能力与一线技术执行力，能够支撑项目4课题9任务的全周期推进。

## 二、负责人与骨干

**项目负责人 柯文彬，** 高级经济师，现任广东公司总经理，担任本项目课题负责人。柯文彬全面统筹项目技术路线制定、资源调配与里程碑考核，对项目整体目标与交付成果负总责。

**核心骨干：**

- **王天智，** 36岁，高级工程师，负责项目整体推进实施，是项目日常执行的核心协调人，承担各课题间进度衔接与任务落地跟踪。
- **董福海，** 47岁，高级工程师，担任项目总指导，把控项目整体质量标准与技术方向，为课题研究与平台建设提供高层级技术决策支持。
- **蔡志权，** 45岁，中级工程师，负责把控课题整体方向与项目方法研究，确保各课题的研究路径与方法论科学合理。
- **李春龙，** 42岁，中级工程师，担任课题技术指导，深入参与绿电溯源、目标分解、大模型预测等关键技术攻关的指导工作。
- **晋智红，** 49岁，高级工程师，负责成果转化协调跟进，推动研究成果向标准化产品与示范应用转化落地。

## 三、分工结构

团队按"决策管理层—技术研究层—成果转化层"三级架构分工协作：

**决策管理层：** 柯文彬总负责，董福海总指导，王天智整体推进，三人构成项目管理核心，负责方向决策、质量把控与进度统筹。

**技术研究层：** 蔡志权、李春龙分别从方法论与技术路径两个维度指导课题研究；欧丰华（33岁）、钟东长（44岁）、冯文汉（39岁）、邹世明（36岁）、王春磊（33岁）五位中级工程师承担项目技术支持，覆盖绿电消费溯源与用能结构优化、区域降碳目标分解评估、大模型能效预测、标准化平台研发与示范部署等核心研发任务。

**成果转化层：** 晋智红牵头，王建宁（41岁，中级工程师）、魏飞强（36岁，中级工程师）、骆耀科（39岁，电力工程师）协同推进，负责研究成果的产品化封装、示范场景对接及可复制推广路径的验证与落地。

## 四、能力支撑

**专业能力覆盖：** 团队成员专业背景涵盖经济管理、电力工程与综合能源技术，能够匹配本项目在能源数据挖掘、碳排放核算、绿电溯源、人工智能预测、平台开发及示范应用等方面的多学科交叉需求。

**质量保障机制：** 项目实施期间设置启动、中期、验收三次专家咨询（每次7位专家半天评审），以外部专家评审与内部技术协调相结合的方式，持续保障各课题研究质量与交付成果水平。

**成果落地能力：** 团队中成果转化人员占比近三成（4人），专职负责标准化产品集成与不少于3家规上工业企业的示范接入验证，确保研究成果从技术攻关到产品落地的完整闭环。项目最终交付包括3份关键技术研究报告、发明专利3项、软著1项、核心论文2篇及1套具备CNAS/CMA资质的标准化平台，团队分工与人员配置已充分对应上述交付要求。
