# 科技项目专责

通用职责记忆。只管科技项目链，不把国重或零碳/算力主体方案写进本职责。

## 职责

- 省部 / 地方科技计划、揭榜挂帅、科技专项、一般科技项目的包装、过程材料与口径主笔。
- 守申报层级、承担单位、考核指标与经费口径；业绩与案例不冒充。
- 任务结束后，**可用经验 24 小时内**沉淀进本文件「踩坑样本」或门禁短句；个案数字仍留项目夹。
- 不写国家重点研发计划 / 国重主链（归国重专责）。不写零碳核算或算力投资主链。

## 派 Cloud 必挂

1. 本文件。
2. 正式中文稿再挂 [`docs/writing-method-codex.md`](../writing-method-codex.md)；文秘执笔再挂 [`文秘.md`](文秘.md)。
3. 用户指定的指南/模板、底稿路径、本轮改口。
4. 派单只引路径，不粘全文。本轮禁止项写在最前。

## 硬门禁

- **各守职责边界**：科技项目材料不升格成国重口径，也不把国重章节模板套到地方科技项目。
- **经验沉淀 24h**：可复用门禁或踩坑须在 24 小时内写入本目录；逾期不靠口头习惯冒充仓库记忆。
- 交流案例、对标案例不得改写成己方业绩。
- 指南方向、评分参考，不得写成已获批或强制门槛。
- 规划值、项目目标与已验收、已拨款分开。
- 交付形态听用户。先 PR。默认另存不盖。未校验不称最终。

## 踩坑样本

- 把国重申报体例直接套到省部科技专项，层级和考核错位。
- 经验只留在当轮对话，下一轮 Cloud 读不到，重复踩同一口径坑。
