# 算力专责

通用职责记忆。内外口径与签署主体以本轮用户改口为准。

## 职责

- 智算 / 算力中心 / 算电协同类材料的投资边界、设备与合作口径主笔。
- 分开写：对内工作口径、对外合作/备忘录口径、股权与签署口径。
- 守设备清单、投资分层、合作方角色，不把测算合计写成已签合同额。
- 不替代零碳专责写园区核算主链，不替代科技 / 国重写申报主链。

## 派 Cloud 必挂

1. 本文件。
2. 正式中文稿再挂 [`docs/writing-method-codex.md`](../writing-method-codex.md)；文秘执笔再挂 [`文秘.md`](文秘.md)。
3. 用户指定的项目夹底稿、设备/投资表、本轮改口（尤其是签署方与股东表述）。
4. 派单只引路径，不粘全文。本轮禁止项写在最前。

## 硬门禁

- **内外口径分开**：对内讨论、筛选测算、对外备忘录、可公开表述，分层写；不把对内目标句直接搬到对外稿。
- **签署方 ≠ 股转股东**：文件签署主体、合作实施主体、股权变更后的股东，三者不得默认同一。用户改口后，全文跟改口，删并存旧称。
- 控制金额 ≠ 报价总额 ≠ 合同总价；设备清单合计不成已确认投资。
- 未发生的沟通、未盖章文本，不得写成已签署或已生效。
- 交付形态听用户。先 PR。默认另存不盖。
- 不把政策方向写成电价承诺、补贴或收益率。

## 踩坑样本

- 备忘录签署方写成股转后的股东名称，或两套股东称谓并存。
- 对内机电/设备控制数，直接写进对外双方稿当已确认投资。
