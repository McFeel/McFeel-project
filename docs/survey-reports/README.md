## 改稿流程

第一步，改 `2026-08-南网总部基地绿色近零碳智慧园区项目调研报告.md`。

第二步，执行 `python3 docs/survey-reports/build_docx.py` 重新生成 Word。

第三步，执行 `python3 docs/survey-reports/check_writing_constraints.py` 复核，该脚本同时校验 Word 与 Markdown 是否同步。

若直接在 Word 中改稿，请把改动同步回 Markdown，否则下次生成会覆盖。

## 公文体例

A4 页面，上37毫米、下35毫米、左28毫米、右26毫米页边距；封面单独成页且不占页码；标题黑体小二号居中，副题楷体_GB2312 三号居中；正文仿宋_GB2312 三号，首行缩进2字，行距固定值29磅；层次依次为一、（一）1.，分别用黑体、楷体_GB2312、仿宋_GB2312加粗；表格五号，跨页重复表头；页码居中，采用“— 1 —”形式。不设红头，不加生成工具提示。

字体名称按 Windows 版 Word 的中文字体命名写入文档。在未安装仿宋_GB2312、楷体_GB2312 的环境中预览时会回落到其他中文字体，属正常现象，不影响在 Word 中的显示。

## 引用约定

第一，正文事实性内容分别来自建科院宣讲材料、交流纪要、公开报道和调研计划四类资料，凡引用均标注出处；宣讲材料与公开报道的数据未经核证，不作为本项目的设计输入。

第二，“零碳区域”一词仅用于转述住建部认证体系的对象划分，不用于指称本项目；本项目一律称南网总部基地绿色近零碳智慧园区或零碳智慧园区。

第三，“全国首个零碳机房”仅为8月19日会内提出的争取方向，不得引述为已申报或已确认事项；宣讲材料中雄安等项目的“首个”表述属对方口径，引用时须写明据宣讲材料。

第四，清华大学一站在成稿时尚未开展，相关内容只有拟交流重点与可能的咨询接口，不得引述为调研结论。

第五，审查说明供内部审阅核对依据使用，不随正文一并对外提供。
