## 名称约定

本文件名称为《调研报告：南网总部基地北京调研》，用于封面主标题、页眉、文件名与 Word 文档标题。正文中提到项目本身时仍称南网总部基地绿色近零碳智慧园区，或简称零碳智慧园区。两者不混用。

## 改稿流程

第一步，改 `调研报告：南网总部基地北京调研.md`。

第二步，执行 `python3 docs/survey-reports/build_docx.py` 重新生成 Word。

第三步，执行 `python3 docs/survey-reports/check_writing_constraints.py` 复核，该脚本同时校验 Word 与 Markdown 是否同步、Word 标题与页眉是否与文件名称一致。

若直接在 Word 中改稿，请把改动同步回 Markdown，否则下次生成会覆盖。

## 公文体例

A4 页面，上37毫米、下35毫米、左28毫米、右26毫米页边距；封面单独成页，不设页眉页码；正文页眉居中书文件名称、下加横线，页码自1起居中并采用“— 1 —”形式。标题黑体小二号居中，副题楷体_GB2312 三号居中；正文仿宋_GB2312 三号，首行缩进2字，行距固定值29磅；层次依次为一、（一）1.，分别用黑体、楷体_GB2312、仿宋_GB2312加粗；表格五号，跨页重复表头。不设红头，不加生成工具提示。

字体名称按 Windows 版 Word 的中文字体命名写入文档。在未安装仿宋_GB2312、楷体_GB2312 的环境中预览时会回落到其他中文字体，属正常现象，不影响在 Word 中的显示。

## 引用约定

第一，正文事实性内容分别来自建科院宣讲材料、三份交流纪要、中移园建产品资料、公开报道和调研计划五类资料，凡引用均标注出处；上述数据均未经本次调研核证，不作为本项目的设计输入。

第二，清华会谈中的用电量、节能潜力、单位成本等数字为会中口述或会中估算，标注后照录，不得表述为已核证或已验收；中移产品资料的成效数字标注为资料宣称，其中楼宇自控改造一组另注为预测值。

第三，“零碳区域”一词仅用于转述住建部认证体系的对象划分，不用于指称本项目。

第四，“全国首个零碳机房”仅为8月19日会内提出的争取方向，不得引述为已申报或已确认事项；宣讲材料中雄安等项目的“首个”表述属对方口径，引用时须写明据宣讲材料。

第五，清华会谈已于2026年8月21日开展，但会中形成的采购与合作安排在完成前不得表述为已签约、已立项或已完成采购。

第六，审查说明供内部审阅核对依据使用，不随正文一并对外提供。
