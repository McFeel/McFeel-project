## 与 PR #61（`hq-base/plan-six-elements-20260902/`）的区别

- PR #61 是**论证型报告**：摘要、立意、四层政策束、六边各一章“本章结论—为什么—怎么做—对标待核—沉淀什么”、待核清单。用户否掉，原因是写成了给领导看的报告。
- 本稿是**规划方案**：目标—布局—专项—项目库—分期。政策论证只在“规划依据”一节点到即可；缺数据处就地标【待核】，不再单设待核清单章。
- 口径变化：近零碳是园区目标属性，绿色与智慧是两条主专项；六要素（绿色、高效、智慧、普惠、健康、人文）落到专项与指标体系，不再各自成章。
- 与 8/27 沙盘（`hq-base/hexagon-race-4/sandbox/`）的旧六边（含零碳占边）也不同，不照搬旧六边当目录。
