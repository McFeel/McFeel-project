落版：小七。本轮**没有生成任何示意图或效果图**，只做三件事：复用仓库里已有的 hq-base 图片、按 Box 素材的文件名把图位挂好、缺的挂占位框并在这里登记文件名。

## 怎么补图

把图片按下表的**路径和文件名**拷进本目录，刷新页面就出图，**HTML 一个字都不用改**。

图位是自动兜底的：图片在，显示图片；图片不在，退回虚线占位框，框里印的就是它等的那个文件名。所以补一张出一张，不用一次配齐。

云端环境读不到 Box 和 Mac 本地盘，下面标「待拷入」的都要在本地由小七从 Mac／Box 拷进来。

## 五、补图要求

- 优先用总部基地和三个调研现场的**实拍**；示意图只在流程、爆炸图这类讲不清的地方用，不要用渲染效果图冒充实拍。
- 横图，短边不低于 1600 px。10 和 11 两页的框是 16:10，15—17 三页的框是 16:9；图会按 `object-fit:cover` 居中裁切，主体别贴边。
- **图内自带的数字、百分比、角标一律只当画面元素看，不改文案、不进对照表。** 页面上所有数字的口径由三包 md 管，落版不动数字。
- 奖项、认证标识、可识别人脸不要入镜。
- 文件名照抄上表，大小写和连字符要一致；扩展名统一 `.png`，换成 `.jpg` 的话要同步改 HTML 里的 `src`。
