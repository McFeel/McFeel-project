战略对齐

总部基地建设本质上是一项战略能力建设

国家推全面绿色转型，公司建生态强企，园区把两件事落到地上。

  1. 国家

    绿色转型从单项节能，转向能源、建筑、数字化和运行管理协同推进。

  2. 依据

    节能降碳行动方案（国发〔2024〕12 号）、新型电力系统行动方案（发改能源〔2024〕1128 号）。

  4. 园区

    战略要求落成能建设、能运营、能验证的园区能力——能碳基线、设备提效、数字底座、智慧运营、健康环境、电网互动。

Constraints · 03 / 23
四道约束

现实约束决定了零碳要靠系统能力

零碳不是多装几台设备就能到，这个园区有四道绕不开的约束。

  1. 负荷重

    数千人连续办公，冷站和数据机房是全年大户。

  2. 资源紧

    屋顶光伏空间有限，外立面和历史风貌不能大改。

  3. 不能停

    办公一天也停不得，改造必须可分区、可并行、可回退。

  4. 专业多

    能源、建筑、数字化、运维分头推进，容易碎成一堆单项工程包。

出路是需求侧节能、本地可再生、绿电交易、柔性互动和碳核证合起来发力，单项工程解决不了。

总体目标

打造世界一流
智慧零碳园区

目标先立住，然后回答一个问题：什么叫世界一流。

  3. 零碳的档位，等能碳基线核定后再比选。

世界一流是我们要建成的目标，不是已经戴上的帽子。

属性三 · 普惠

普惠：一个规则，人人可及

普惠讲的是人人参与、人人受益，同一件事对所有人一套规则。

  1. 通行

    入园、停车、充电一次约好，员工、外包、访客走同一套流程，闸机前不用问人。

  2. 车位与充电

    车位和充电桩按同一队列排，先约先用，不留专属位。

  3. 用餐

    食堂时段和排队时长公示，谁都能提前挑一个不挤的点去。

  4. 运动与共享

    文体场地、共享会议室、母婴室在同一个入口预约，额度和余量公开。

  5. 无障碍

    坡道、盲道、无障碍卫生间按标准做齐，坐轮椅能自己走完全程。

普惠看的是同一套规则对所有人有效，不是给谁额外的优待。

Human Health · 16 / 23
属性四 · 健康

健康：空气、光、声、温湿度可测可调可公示

健康不靠说法，靠四项环境数据能测、能调、能看得见。

  1. 空气

    每层布点测二氧化碳和 PM2.5，超过阈值自动加新风。

  2. 光环境

    办公区照度和色温分区可调，靠窗自动遮阳，屏幕不反光。

  3. 声环境

    开放办公、专注舱、电话间分开做声学处理，各区噪声定各自的限值。

  4. 温湿度

    可调工位是常态，每个人在手机上就能微调自己工位的风口和送风温度。

  5. 公示

    每层电梯厅一块环境牌，实时数值和当日达标时长都写在牌面上。

健康数据只用于改善环境和验收，不进个人考核。

属性五 · 人文

人文：一次预约联动末端，一次参观看见运行

人文是把运行变成场所感：会议一预约末端就动，客人一进园就看见真实运行。

  1. 会议

    预约就是末端开关，人到灯亮风起，散会自动回落。

  2. 联动

    会议改期或取消，空调照明跟着改，空房间不再空转。

  3. 参观路线

    客人走的是运行现场，冷站、屋顶光伏、楼层配电依次看得到。

  4. 碳账本

    最后一站看正在记账的碳账，当日发电、用电、降碳量当场翻给客人看。

  5. 现场解说

    说明牌贴在设备旁边，参观走完，园区照常办公。

参观看的是正在运行的园区，不建独立展馆。
