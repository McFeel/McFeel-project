一页说清规划主线

改什么

底座一次到位，工程分期落地

  • 冷站与机电：诊断—群控—蓄冷接实时电价，不换主机优先
  • 数字底座：一个平台、两类功能、四级计量
  • 碳账：全园总账 + 办公区 / 机房子账
  • 生态与场所：微气候、海绵、无障碍、真实系统展项
改到什么水平
  • 2028：低碳档 · 园中园试点跑通一个供冷季
  • 2030：近零碳档 · 绿色智慧近零碳园区建成
  • 冷站能效较基期：2028 ≥10%，2030 ≥15%待核
怎么布 · 怎么分期
  • 空间：既有格局不变 · 系统重组 · 节点更新
  • 三件先行：冷站诊断 · 碳账本 · 平台总体设计
  • 路径：园中园试点 → 全园推广 → 内园复制
第一章

规划范围 · 期限 · 依据

范围

既有园区全边界

  • 办公楼群、冷站与冰蓄冷、数据机房
  • 供配电与既有光伏、充电设施
  • 道路庭院绿地与信息化系统
  • 碳账：全园总账 + 办公 / 机房子账
期限

基期 2027 · 三期推进

  • 近期 2027—2028：基线 · 试点 · 低碳档
  • 中期 2029—2030：全园推广 · 近零碳档
  • 远期 2031—2035：深化运营 · 内园复制
定位与原则

验证场，不是第二曲线

  • 总部基地 = 战略资产价值体系验证场
  • 能源公司主笔牵头，战略主体是南网
  • 不停机分区 · 先测后改 · 一次规划分期建 · 可复制

依据：国家节能降碳与近零能耗相关规范、公司既定安排与调研材料；建设方案 V3 仅作家底与卡点参考。政策文号不在投屏展开。

第二章

现状卡点 · 规划怎么应对

家底量级待核
约 5000 人持续办公
年用电约 7000 万度
空调办公约一半用电
既有光伏约 2 点几兆瓦
机电 2016 投运满十年
外立面不可大改

尚未建立碳账本；基期以 2027 供冷季实测 为准，基线前降碳率只给台阶、不给绝对值。

六条硬约束
  • 不停机 → 园中园、分区试点，控制回路与增量设施为主
  • 风貌限立面 → 光伏上屋顶/车棚，微气候靠庭院
  • 设备未到报废 → 先诊断分档，不换主机优先
  • 屋顶光伏有限 → 降碳主力是需求侧节能 + 绿电交易
  • 实时电价转向 → 蓄冷策略与交易接口列为近期必做
  • 机房口径未定 → 先立总账加子账，再定档
第三章 · 目标

到 2030：绿色 · 智慧 · 近零碳园区

近零碳

目标属性

2028 低碳档 → 2030 近零碳档。路径：需求侧节能 → 本地光伏 → 绿电交易 → 合规抵消。

绿色

能与碳 · 水与生态

冷站高效化、柔性资源接电价；海绵与微气候；室内环境连续达标，节能不以空气品质为代价。

智慧

数字底座与运营

一个平台、两类功能；四级计量两用；模型本地化部署，数据主权归南网。

绿色 · 高效 → 近零碳与能源 / 生态专项 智慧 → 智慧运营专项 普惠 · 健康 · 人文 → 专项与指标，不再各自成章

六要素落到专项与指标体系；产出除工程实体外，须可带走方法、数据或规则，供南网内园区复用。

第五章 · 专项一

近零碳与能源 · 绿色 / 高效主路径

第一步

需求侧节能

冷站群控、末端联动、机电调优

第二步

本地光伏

屋顶 / 露台 / 车棚应装尽装；立面不布置

第三步

绿电交易

按近零碳档缺口采购，来源可溯源

第四步

合规抵消

控制在标准上限内待核

冷站主战场

诊断—分档—改造—调优；不换主机条件下节能潜力约 10%—20%待核。

蓄冷接电价

过渡期 + 稳态期两套策略；约 15 分钟级实时电价接口待核。

机房与柔性资源

机房子账、余热摸底；蓄冷 / 光伏 / 充电 / 算力负荷进柔性资源池。

第五章 · 专项二

绿色生态 · 水、微气候、半开放空间

水循环与海绵

透水 · 雨水 · 中水

  • 道路广场透水铺装
  • 雨水回用于绿化水景
  • 中水回用范围研究
  • 试点场地先行
植被与微气候

乔木 · 廊道 · 遮阳

  • 增补乔木与垂直绿化
  • 组织通风廊道
  • 室外环境监测入平台
  • 以实测验证改善效果
半开放空间

架空层 · 连廊 · 庭院

  • 遮阳通风的休憩健身场所
  • 1 号楼后空地作首个试点待核
  • 不改变建筑外立面
  • 为健康、人文提供空间界面

园外侧

实时电价与需求响应 · 绿电与碳核算 · 南网内其他园区复用接口

第五章 · 专项点到

普惠 = 人人参与 · 人人受益

不是投资收益，不是产品复制对外服务包。无障碍为标配。

碳普惠

个人—团队—园区三级账

  • 通勤、用能、会议、无纸化自动记账
  • 园区总账人人可见
  • 对接广东 / 广州碳普惠方法学待核
  • 积分兑换园区文体与服务
算力普惠

全员开通 · 用量透明

  • 办公助手、知识库、会议纪要等
  • 申请门槛低
  • 与算电协同共用算力底座
  • 控制性：全员开通（2028 / 2030）
园区资源普惠

公平可及 · 规则公开

  • 充电、会议、文体、餐饮、共享空间
  • 员工 / 外包 / 访客统一预约
  • 部分公共空间双碳科普开放待核
  • 全域无障碍排查整改
第五章 · 专项点到

健康可检可验 · 人文风貌延续

健康

对象是可验收的环境与服务

  • 楼层监测公示：CO₂、PM2.5、温湿度等接入平台
  • 新风与净化：与冷站诊断同步；节能与健康互锁
  • 节律照明与工位微环境：与末端联动同步实施
  • 健身休憩与心理健康：边角与半开放空间承载
  • 健康数据只用于改善与验收，不用于个人考核
人文

场所品质 · 真实系统展示

  • 针灸式更新：入口、连廊、庭院、灰空间；外立面大改 = 0
  • 真实系统展项：运营中心、冷站、碳账、柔性调控实况
  • 不建独立展馆、不做大屏秀
  • 节事与碳普惠、资源预约打通，形成日常获得感
