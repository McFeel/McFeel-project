# 南网总部基地既有园区重新升级 · 顶层六边形框架（GLM-5.2 第三轮赛马）

> 口径承接：科学城既有园区（调度 / 信息 / 党校 / 档案 / 后勤 / 宿舍）；
> 8.19 建科院「零碳为底 + 健康 / 智慧 / 人文、第六边未命名」、8.21 清华「六边形战士、园中园」、
> 8.26 能源公司「员工获得感、碳普惠 / 全员减碳 / 园区总账」、9 月中旬方向汇报；
> 钱课题锚点：**可迁移能力、验证场不是第二曲线**。
> 本版完全跳出原建设方案 V3：不用其设备清单与卡点作骨架，绿色高效只占一边，另五边为独立维度。

## 一、主张：六边不是六个系统，是六种可迁移能力的咬合

既有园区「重新升级」的本质，不是把六类工程并列堆叠，而是把基地当作**能力的验证场**：每一边都要在「人还在、系统还在跑」的真实园区里被证明三件事——能不停机部署、能被结果（而非设备）度量、能被复制到南网其他存量园区与站点。**升级产出的是可迁移的方法，不是一座样板园，更不是第二曲线。** 这一条是六边的公共脊梁，也是本版与前两轮的根本分野：建科院以零碳为底、清华以园中园为形、能源公司以员工获得感为账，本版以「验证场 + 可迁移」为骨。

## 二、六边（是什么 / 为什么 / 怎么办）

### 边一 · 碳账能力（唯一绿色边）
- **是什么**：把园区碳排做成可结算、可分摊、可参与的「总账 + 普惠」方法——按楼栋 / 单位 / 个人三层归集，调度楼、信息楼、党校、档案、后勤、宿舍各自一本账，员工一本个人碳账。
- **为什么可迁移**：南网存量园区众多，缺的不是减碳设备，而是「谁来结账、按什么口径结、结了谁受益」的制度。制度可复制，设备不可复制。
- **怎么办**：先立口径与分摊规则（不先买设备），用既有计量做最小账本，跑通一个结算周期后再补测点；碳普惠与全员减碳挂到员工获得感，但**只买规则与核证，不买碳指标**。

### 边二 · 在用不停能力
- **是什么**：在「人未搬、电未断、网未停」的既有园区里，完成能源、信息化、围护、水系统的逐项升级而不中断服务的能力。
- **为什么可迁移**：这是「既有升级」区别于新建的唯一硬门槛。能不停，才能复制到任何在运站点；不能不停，就只是拆了重建。
- **怎么办**：以「切片升级 + 影子并行」为单位，每一边都先证明「停服窗口为零」再动工；任何一边若必须疏散或断服才能落地，该边退回重设计。

### 边三 · 健康可感能力
- **是什么**：把不可见的室内环境质量（PM2.5 / CO₂ / 照度 / 夜噪 / 热舒适）变成员工可看、可议、可改善的「可感健康」。
- **为什么可迁移**：存量园区的健康痛点是「感觉差但说不清」。能把它变成可量化、可归责、可闭环的指标，方法就能搬到任何办公园区。
- **怎么办**：以宿舍与调度楼为先行切片，建最小感知—反馈闭环；指标对个人可见、对后勤可派单，**不建独立健康平台，并入园区一图**。

### 边四 · 智识自洽能力
- **是什么**：感知—决策—执行在园区内部闭环，能源、健康、安防等回路「自洽运行」，不靠远端值班保姆式托管。
- **为什么可迁移**：南网不缺智慧单点，缺的是「能自己跑起来」的自洽模式。模式可复制，单点不可复制。
- **怎么办**：先选一两个回路（如夜间的健康—能耗联动）做端到端自洽，验证「无人值守不退化」；**只买通用平台与算力，不买整体智慧方案**。

### 边五 · 场域认同能力
- **是什么**：把科学城里一块通用地块，做成外人一眼可辨的「南网人的园」——命名、仪式、档案与党校作为身份锚点，而非单纯功能用房。
- **为什么可迁移**：存量园区最易被「修旧如新却失了魂」。能系统性地赋予并维持认同，是可复制的场所营造方法，区别于清华「园中园」的空间概念，本边是「认同可被验证」的方法。
- **怎么办**：以档案楼、党校为认同载体做最小改造，验证「非南网访客能否在十分钟内辨认此处归属」；**不外包设计总包，只外请命名与文化梳理**。

### 边六 · 韧性承冲能力
- **是什么**：对调度 / 信息总部基地，承住电力、气候、网络、密度四类冲击的吸收—恢复模式。
- **为什么可迁移**：总部基地是关键节点，韧性是底线而非加分项；吸收模式一旦在此验证，可平移到所有关键站点。
- **怎么办**：以「断一路电源 / 断一回路 / 极端天气 / 临时减员」为四类压力测试脚本，逐边做最小承冲演练；**只买冗余硬件，不买应急外包**。

## 三、咬合：六边共享三条缝

六边不是六个孤岛，靠三条共享缝咬合成一体：
1. **一图缝**：碳账、健康、智识、韧性共用同一张园区数字底图与同一套测点，不各建各的图。
2. **一账缝**：碳账的归集口径，同时是健康可感、智识自洽、韧性承冲的结算底座——一张总账养六边。
3. **一证缝**：六边共用同一套「可迁移验证」证据链——每一边都要拿出「在此园区跑通 + 在第二个园区可复用」的双证，否则不算过关。

## 四、两闸（过闸才推进）

- **闸一 · 不停闸**：任何一边若需疏散人员或中断调度 / 信息主业才能落地，即不过闸，退回重设计。这是既有升级的生死闸。
- **闸二 · 可迁移闸**：任何一边若只能在本园区成立、换一个园区即失效，即不过闸，降级为单点工程而非能力。这是验证场的定义闸。

## 五、外请只买什么

基地是能力锻造场，**只买三类外部物，三类一律不买**：
- **只买**：标准化硬件与通用平台（算力、传感器、冗余件）、第三方独立验证（核证 / 测评）、命名与文化梳理的轻咨询。
- **不买**：整体解决方案总包、长期运营外包、数据所有权与碳指标。能力与方法必须留在南网自己手里，否则「可迁移」失语。

## 六、三条不做

1. **不做展示工程**：不为汇报做样板段、不建参观动线、不堆可视化大屏；每一边的产出必须是可复制的方法与证据，不是可看的场景。
2. **不做设备换新**：不以 V3 设备清单为骨架逐项替换；设备只在能力需要时按需补，不让「换设备」冒充「升级」。
3. **不做第二曲线**：不为南网开辟新业务线、不对外卖方案卖运营；本园区是验证场，产出是可迁移能力，不是新收入来源——这是钱课题的底线，也是本版的边界。
