# 南网总部基地既有园区升级：六边形战士顶层框架

> 赛马里 Grok 4.6 路 · 预可研级主张稿。不报未核实数字，不写未签约合作。

既有园区最容易写成「零碳 + 四个形容词」。那是拼盘，不是六边形。杨旭东要的是木桶：每边不追全球最尖，但每边都够长。建科院是零碳打底、四向拓展。综二处是员工摸得着、账算得清、能源公司交得出。三句话对不齐，就是平均稿。

**主张：前五边接住建科院已落纸的结构；第六边补纪要没点名、但综二处已把验收说死的「总账」。机房、好房子是专项，挂边不占边。**

## 1. 六边

1. **零碳底盘**：钉死既有园区的碳边界、国标基准值 / 引领值、绿电采购 + 楼宇节能 + 光伏三条路径，对外只讲路径。  
   为何是这一边：零碳是打底，不占边则后四边漂成口号。对建科院：承接「零碳为底」，从态度收成可审计边界。

2. **能源可运行**：改造必须并进日常运行；光伏 / 微风只做星星点点展示。  
   为何：建科院概念方案的专业主边，也是能源公司主场。对建科院：同意能源是边，收窄为可运行，禁止能源秀。

3. **智慧能调度**：只服务计量、告警、碳账与机房突破口。  
   为何：既有园区短板是看不见、调不动，不是缺大屏。对建科院：承接智慧拓展，降为神经，不另立中台中心。

4. **健康在日常**：空气、热湿、光、声与通勤尺度上的可感知改善。  
   为何：建科院点了健康，综二处要获得感。对建科院：边保留，验收从证书挪到工作日。

5. **人文是场所**：公共空间、礼仪动线、食堂与班后场所能被使用。  
   为何：建科院点了人文；既有园区最易做成展板。对建科院：边保留，对象从文化表达收成场所使用。

6. **总账能关门**：园区总账、楼宇 / 组织账、个人碳普惠账必须对得上。  
   为何：这是第六边。纪要未点名，但 8 月 26 日已把碳普惠、全员减碳、园区总账一体化和「不停留在证书」写成验收。韧性、示范、好房子、机房是属性或专项，不配做第六边。对建科院：不是否定 1+4，是把综二处的运营验收补成承重边。

## 2. 一层目录

**总定位。** 广州南网总部基地既有园区近零碳综合提升，不是新建园。深度停在预可研：先概念，后全过程咨询。几何是园中园 / 分区试点。机房是突破口专项——内部可争「全国首个」，对外不承诺。

**六边如何咬合。** 零碳底盘是坐标系；能源是肌肉，智慧是神经，健康与人文是员工天天碰到的皮肤；总账是关节，项目、计量、碳普惠、预算在此会合。机房挂在零碳 + 能源 + 智慧下；好房子挂在健康 + 人文下。六边并列展览即失败。

**两道闸。** 闸一：9 月中旬方向稿给两位主任，只回答是不是这个六边形、先打哪个园中园、三条不做、外请买什么。深圳广州调研与写稿并行，不等人家调研闭环；不报投资额、未测电量、未做认证。闸二：框架通过后，网公司分阶段安排预算。总账列不清阶段边界、试点范围、外请科目，不放段。

**外请只买什么。** 能源公司按已立专项买切片，不买总包叙事：①本公司不具资质的健康 / 人文技术方法；②国标基准值 / 引领值对标与边界校核（学移动信息港的认证纪律，不买证书）；③三本账科目如何对账。不买全过程咨询，不买品牌包装。

**能源公司如何主笔。** 母本只出能源公司：总定位、六边、咬合、两闸、三条不做。外请是附件。禁止「顾问出框架、能源公司填数」。深穗调研由能源公司出提纲和总账口径，回灌母本，不另起一稿。专项写附件，不回流成定位边。最终交付权在能源公司。

## 3. 对国网雄安 / 博鳌

不评价两家投资与成绩（无授权数据）。只钉三处。对象：它们适合示范性新建 / 会展叙事，这里是员工上班的既有总部。成果：它们可以证书先行，这里证书是副产品，闸门是工作周里的获得感。账：碳普惠三本账是差异化装置——园区总账对网公司预算闸，楼宇 / 组织账对部门运行，个人账对全员减碳。三本账对不上，不算交卷。雄安 / 博鳌可以没有员工侧账；这里没有，就不交。

## 4. 三条不写 / 不做

1. 不对外写「全国首个零碳机房」，不把未签约合作写成已落地。
2. 不写光伏 / 微风能改变园区负荷结构，不写未核实的用电量、投资额、认证结果。
3. 不把好房子、零碳机房、韧性、国际对标写成第六边；不先买全过程咨询再补概念；不把方向稿写成可研。
