# 南网总部基地既有园区升级 · 六边形战士框架（Kimi K3 版）

## 一、六边主张

总定位：零碳打底、韧性立身、员工有感——把既有园区做成"天天用得上"的近零碳综合提升样板，不做第二块展示牌。

1. **零碳（底边）**：近零碳是全部改造的标尺，先算园区总账、再定项目盘子。这是徐伟"零碳为底"的原意：底边不与其余五边争长短，是它们的及格线。
2. **能源**：机房突破口先行，光伏、微风作"星星点点"展示，主路径走绿电采购加楼宇节能。直接接住 8·19"机房作突破口"与 8·20 移动信息港已验证的减碳路径，不另起炉灶。
3. **智慧**：一套能碳平台统管计量、调度与碳普惠数据，服务园区总账。对应建科院"智慧"边，但收窄为"管账工具"，防止做成大屏工程。
4. **健康**：按国标基准值、引领值做室内环境与节能健康一体化改造。对应"健康"边，认证口径沿用国标两档，不自创标准。
5. **人文**：把南网历史织进员工日常动线，人文落在使用场景而非展陈。对应"人文"边，落点是员工，呼应综二处"获得感不停留在证书"。
6. **韧性（第六边，本文主张）**：配电、储能、应急与防台风能力整体升级，让总部园区成为电网韧性的活标本。纪要未点名第六边，我主张给韧性：电网企业的看家本领是韧性，广州台风高发，既有园区最缺的恰是这一边；对建科院口径，韧性是"零碳为底"的物理承载——极端天气下园区掉链子，其余五边归零。

## 二、最简框架（一层目录）

1. **总定位**：既有园区近零碳综合提升，零碳打底、韧性立身、员工有感。
2. **六边咬合**：零碳定标尺、能源给路径、智慧管总账、健康人文落场景、韧性兜底线；按杨旭东木桶逻辑，不追单边全球最尖、追六边整体够高，园中园分区试点，每区六边全配、深浅可调。
3. **两道闸门**：第一道，9 月中旬方向稿，只讲定位、六边与分区试点先后，供两位主任定方向；第二道，网公司分阶段预算，框架预留分阶段安排，预算随阶段闸口分批释放，不一次要足。
4. **外请只买三样**：概念方案（延续建科院口径）、已立专项的专项论证（机房、好房子等）、认证咨询（国标两档路径）；战略与定位自己写，全过程咨询待概念方案过闸后再议，外请由能源公司按已立专项落实。
5. **能源公司主笔**：主笔并最终交付，一个声音成稿；深圳、广州调研与写稿并行；建科院、移动信息港、清华三方输入只作附件口径。

## 三、与国网雄安、博鳌的差异化

雄安、博鳌是新建展示窗口，做的是"技术橱窗"；我们是既有园区、是总部、是员工每天上班的地方。差异化三条：

- **员工获得感为第一指标**：环境、通勤、参与感进验收口径，不停留在证书。
- **碳普惠三本账一体化**：个人碳普惠账、全员减碳账、园区总账三账打通，员工减排可计量、可兑换、可上墙——新建展示园区做不了，既有总部园区独一份。
- **韧性边即电网身份**：雄安、博鳌不必回答"台风天园区怎么办"，我们必须回答；答好了，就是南网独有的叙事。
