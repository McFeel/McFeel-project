# 图位清单 · 完整歸藏瑞士风领导汇报 HTML

把图片按下表的**路径和文件名**拷进本目录，刷新页面就出图，**HTML 一个字都不用改**。

图位是自动兜底的：

- **实拍位**（`photo-slot`）：图在就显示图；图不在就退回瑞士风网格占位框，框里印的就是它等的那个文件名。
- **逻辑图位**（`logic-img`，`logic/` 目录）：PNG 在就用 PNG 铺满整块图区；PNG 不在就回落到页面内联的瑞士风 SVG 逻辑图。

补一张出一张，不用一次配齐。云端读不到 Box 和 Mac 本地盘，下表标「待拷入」的都要在本地由小七拷进来。

- 宽 ≥ 2400 px；横向长条比例（约 3:1 ～ 21:9）最贴合图区；图区按 `object-fit:contain` 显示，不会裁切，比例不一致只会留边。

## 七、通用补图要求

- 优先用总部基地和三个调研现场的**实拍**；示意图只在流程、爆炸图这类讲不清的地方用，**不要用渲染效果图冒充实拍**。
- 横图，短边不低于 1600 px；主体别贴边。
- **图内自带的数字、百分比、角标一律只当画面元素看**，不改文案、不进对照条。页面上所有数字的口径由 `copy-source/` 三个 md 管，落版不动数字。
- 奖项、认证标识、可识别人脸不要入镜。
- 文件名照抄上表，大小写和连字符要一致。实拍位扩展名统一 `.jpg`、逻辑图位统一 `.png`；要换扩展名得同步改 HTML 里的 `src`。
