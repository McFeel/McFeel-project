# 02 六条路径落地框架：机库场景 × 334 号指标体系

- 依据：工信部联节〔2026〕13号「建设路径」六条（科学算碳、源头减碳、过程脱碳、协同降碳、智能控碳、碳抵销和信息披露）；指标编号、公式、口径全部引自工信厅节函〔2026〕334号附件1（试行）。
- 用法：本文件是**规划框架**，不是建设方案正文。每条路径给出「机库场景落点 → 关键用能 → 对应指标 → 所需资料字段 → 风险」。资料字段编号与 `03-收资逻辑说明书.md` 中 AM 行一致。
- 前提：01 的结论是当期 `不满足硬性申报条件`；本框架服务于变通选项 A（梯度培育）+ C（自建口径对标建设）+ E（南网能源综合能源服务），同时为后续批次积累统计期数据。
- 标记：【事实】【计算】【判断】【建议】【待核】同 01。
- 场景假设（全部【待核】，仅用于确定收资项，不进入正文数字）：本基地以电力为主要能源；冬季高大空间供暖存在燃气或外购热力；存在地面特种车辆（GSE）燃油；不存在工艺过程 CO2 排放；不存在厂内废弃物焚烧。

## 路径一：科学算碳（健全碳排放核算管理体系）

**机库场景落点**
- 边界：先定申报主体（AM01）与物理边界（AM02）。五大功能区中只把「机务维修设施项目」纳入，还是含运行及保障用房等，直接改变所有分母。【判断】建议按「机务维修区 + 其配套能源设施」划边界，与独立核算口径一致。
- 排放源清单（【判断】机库场景典型项，是否存在均【待核】）：
  - 直接排放：燃气锅炉/燃气热风（供暖、喷漆烘干、复材固化）；GSE 柴油/汽油；维修活动中的航油燃烧（试车、APU 运转）；应急柴油发电机。
  - 间接排放：外购电力；外购热力（若由机场能源中心或市政供热）。
  - 不计入 CO2 口径但需说明：生物质燃烧（单独核算）；制冷剂逸散（非 CO2，附件1 以 CO2 为口径，不计）。
- 方法：GB/T 32150—2025 通则；无 MRO 细分标准时按通则 + 排放因子法【事实】。外购电因子三种方式（附件1 注3 a/b/c）需在方案中**一次选定并保持一致**【事实】。

**关键用能**：电（主）、天然气或外购热（冬季）、燃油（GSE、试车）。

**对应指标**：申报条件(四)；1.1 分子 C；所有分母 E1/E2/Q。

**所需资料字段**：AM01、AM02、AM03、AM06、AM07、AM11、AM13。

**风险**
- 航油燃烧是否计入边界：航空器属南航股份，若北京基地视同法人，维修期间的试车/APU 用油是「本单位边界内燃料燃烧」还是「客户资产用能」，需要核算边界说明并取得省级主管部门认可【判断】【待核】。
- 边界随功能区变化：若含航食生产（燃气蒸煮）会显著拉高直接排放【判断】。

## 路径二：源头减碳（用能结构绿色低碳转型）

**机库场景落点**
1. 屋面光伏扩容（物理认定量的主来源）：1 号机库屋面、附件修理厂房、GSE 车棚。约束：大跨度钢结构屋面附加荷载、防水与运维通道；机场净空与光伏眩光评估（跑道/塔台视线）；并网点与自发自用比例。【待核】AM10。
2. 绿电直连 / 源网荷储一体化 / 绿色微电网：三类均计入 1.3 物理认定量【事实】；北京地区可落地形式与接入条件【待核】。
3. 绿电交易与绿证：进入 1.2 非化石占比（绿证认定量原则上 ≤ 下网电量 50%，须为核销量且生产年度与购买年度一致）【事实】；**不进入 1.3**【事实】。
4. 供暖热源非化石化：高大空间供暖若为燃气，改热泵（空气源/地源/余热）+ 辐射末端，或争取外购非化石热力（热力排放因子可按零计的前提是「非化石能源热力」且来源可溯【事实】）。
5. GSE 电动化：牵引车、平台车、叉车、地面电源车换电动，配套现有 300→800 桩【事实，桩数】；替代 GSE 柴油直接排放。
6. 地面电源/地面空调（400 Hz GPU、PCA）替代 APU：减少维修期间航油燃烧（若计入边界）。

**关键用能**：外购电总量与来源结构、光伏自发自用电量、燃气/热力量、GSE 与试车用油。

**对应指标**：1.1、1.2、1.3（三项核心指标全部在此路径）。

**所需资料字段**：AM03、AM05、AM06、AM07、AM10、AM11。

**风险**
- 1.3 是「工程量」指标：不上真实装机或直连，任何采购型绿电都无法拉动【事实】。
- 北京本省发电煤耗折标值偏低时 1.1 更难达【判断】，需按附件1 注5 取值并说明来源。
- 光伏预期发电量（27 万 kWh）为 2019 年预期值，不能当实测写入统计期数据【事实】。
- 1.2 达 95% 目标要求供暖也非化石化，仅靠电力侧绿电不够【计算/判断】。

## 路径三：过程脱碳（提升能源利用效率）

**机库场景落点**
- 机库大门开启工况与空气幕/分区通风：北京冬季大门开启是最大热损失来源之一【判断】；运行记录与开启时长是能耗诊断的第一手数据（AM04）。
- 高大空间供暖末端：辐射供暖、分层送风、局部工位供暖代替全空间加热【建议】。
- 照明：高大空间 LED 与分区/感应控制。
- 压缩空气系统：空压机能效等级、压力分级、泄漏管理（空压机有能效强制性国标，进入 2.2 统计【事实】）。
- 冷热源与通用设备：冷水机组、热泵、风机、水泵、电机、变压器（均在 2.2「纳入统计范围装备」列举之内【事实】）。
- 工艺设备：热压罐、烘干/固化炉、喷漆房与 VOC 处理（RTO 燃气）——如存在（AM08）。
- 2.3 碳清除率：仅适用于有直接排放的单位【事实】；机库场景一般不做 CCUS，若直接排放趋零，2.3 备注「不适用/趋零」即可【判断】。

**关键用能**：供暖能耗（气/热/电）、照明、压缩空气、冷热源、工艺设备。

**对应指标**：2.1（分母是工业增加值，需 AM13）、2.2（分子分母均为额定功率，需 AM09 台账）、2.3。

**所需资料字段**：AM03、AM04、AM08、AM09、AM13。

**风险**
- 2.1 要求以 2025 年现价为基期核算工业增加值并用 PPI 折不变价【事实】；MRO 的「工业增加值」需要统计部门认可的口径（AM13）。
- 2.2 只统计有能效强制性国标的装备，机库专用设备（升降平台、起重机）多数无适用标准，不纳入【事实】。
- 「主要产品单位能耗达行业领先」需要外部对标值，公开缺失【待核】。

## 路径四：协同降碳（产品碳足迹与零碳供应链）

**机库场景落点**
- 3.1 产品碳足迹分析占比：分母是 B204-1 报表中「主要产品类别总数」【事实】；MRO 的「产品」是维修服务类别（如机体定检、附件修理、发动机/APU 修理等），需先确认统计口径中列了几类（AM14）。【建议】先以「一类典型维修服务（如某机型 C 检）」按 GB/T 24067—2024 做碳足迹试点。
- 3.2 零碳供应链六项：① 管理制度；② 碳数据协同（主要外购产品碳足迹）；③ 供应商培育；④ 资源循环（废旧航材/部件回收处置体系）；⑤ 信息化管理；⑥ 绿色低碳物流（清洁运输比例 ≥85%，建设期满 100%）【事实】。
- 清洁运输口径：铁路、水路、管道及纯电动/氢燃料汽车运输量占进出企业大宗物料和产品运输总量的比例【事实】。机库场景「大宗物料」主要是航材、化学品、油料与废弃物的地面运输；**航空器本身以飞行方式进出不宜计入**，此解释需与省级主管部门确认【判断】【待核】。

**关键用能**：物流车辆燃料（多为外部承运商，范围三性质，但 3.2⑥ 单独要求）。

**对应指标**：3.1、3.2。

**所需资料字段**：AM14、AM15。

**风险**
- 3.1 分母若按 B204-1 口径为 0（未纳入规上工业统计），指标无法计算，反向印证 01 门槛(一)-2【判断】。
- 供应商多为境外 OEM，碳数据协同难度高，只能先从国内航材/化学品供应商起步【判断】。

## 路径五：智能控碳（数字化能碳管理中心）

**机库场景落点**
- 4.1 自动采集率：分母是按 GB 17167—2025 要求应配备的进出用能单位、主要次级用能单位、主要用能设备三级计量点【事实】。机库场景常见缺口：单体建筑（机库/厂房）分表、供暖热量表、压缩空气流量、GSE 充电分计量【判断】。
- 4.2 十三项功能：可以「能管中心 + 碳排放管理系统」组合实现，不要求单一平台【事实】；指标值按平台稳定运行 1 年以上后计【事实】——意味着**建设期第一年基本拿不到分**，要尽早上线。
- 与既有系统对接：BA/楼宇自控、EMS、南航 TAOIX 等生产系统、电网/燃气/热力接口（附件1 注2 认可 API 对接与公用事业接口）【事实】。

**关键用能**：不直接减排，但决定 1.1—2.2 全部数据可信度。

**对应指标**：4.1、4.2；同时支撑申报条件(四)。

**所需资料字段**：AM12（现状计量与系统清单）、AM02（计量边界）。

**风险**
- 计量器具配备率不达 GB 17167—2025 时，4.1 的分母口径会被质疑【事实】。
- 数据安全：机场控制区与航司生产网的数据出网限制【判断】【待核】。

## 路径六：碳抵销和信息披露

**机库场景落点**
- 披露载体：本基地边界的「零碳工厂（维修基地）建设报告」，或在南航集团 ESG 报告中设本基地专节——**必须是本基地边界数据**，不能用集团口径替代【判断】。
- 披露内容：碳排放信息、产品（服务）碳足迹信息、碳抵销情况、建设情况与成效；数据遵循可测量、可报告、可核查【事实】。
- 抵销：只在「充分自主减排、降无可降」之后；国内用 CCER，跨境用《巴黎协定》第六条 ITMOs【事实】。SAF 属集团航空运输侧减排举措，不属于本基地边界抵销手段【判断】。

**关键用能**：无。

**对应指标**：5.1；334 号第三条(六)「按年度持续披露核心指标达成情况」。

**所需资料字段**：AM16。

**风险**
- 把集团 ESG/SAF 数据写入本基地披露构成「串台」，也不满足「分子分母口径一致」的核算原则【事实】。
- 抵销量与绿证重复计算环境价值时会被否定【事实】（附件1 1.2 注1「环境价值不重复核算」）。

## 分期建议（【建议】，年份仅表示先后，不承诺）

| 阶段 | 内容 | 服务的指标 |
| --- | --- | --- |
| 第一步 定边界、补计量、做核算 | AM01/02 定主体与边界；补齐三级计量；出 2025 年统计期碳核算与能源平衡表 | 申报条件(四)、4.1、全部分母 |
