## 证据分级与口径纪律（出口稿必须保留）

- 标记：【事实】公开可查；【计算】按公开公式与参数推算、含假设；【判断】Fable 专业判断；【建议】可选动作；【待核】南航未提供、公开未见。
- 不编造南航未提供的分项用电、电价、装机实测、储能、绿电合同电量。
- 勿串台：大兴机场 100% 绿电 / 机场约 7 MW 光伏 / 航站楼节能 ≠ 本基地成绩；南航集团 ESG / SAF ≠ 本基地承诺。
- 绿证只进「非化石能源消费占比」（1.2）讨论，且原则上不超过下网电量 50%；**不得**计入「非化石能源电力消费物理认定量」（1.3）。
