## 口径卡（本稿严格遵守的工作假设）

- **一核不占边。** 核＝战略资产价值体系（碳账与核算口径、调控与交易模型、数字底座与数据资产、改造与运营方法论），不是资源清单。基地是验证场，对应课题“内部验证—行业复制”，不是第二增长曲线本身。
- **三层立意。** ①国家六张网；②南网以新型电网为枢纽做六网协同，算电协同是当前突破口（“2030 覆盖重点园区”只作报道口径）；③南网自身核心资产＋第二增长曲线。
- **六要素＝六边。** 绿色、高效、智慧、普惠、健康、人文。零碳不占边，托住核与绿色边；健康独立于人文。
- **普惠＝人人参与、人人受益。** 碳普惠、算力普惠、园区资源普惠。不是投资收益、分档报价、EaaS 或可卖服务包（那些归核的复制叙事）。无障碍是标配不是全部。
- **基地是南网整体名片和验证场，不是能源公司展台。** 能源公司只主笔起草。复制先南网内其他园区，再其他央国企。
- **改造论证用四层政策束**（国家方向 → 行业与电网 → 园区与建筑 → 南网自身），不以六张网单点证成。
- **智慧边参照中国移动国际信息港**（预约联动、M-PARK），对外稿不出现内部平台名称。
- **不编文号、不编数据、不用“首个/唯一/领先”。** 稿中没有的一律标【待核】，对标案例也标待核。
