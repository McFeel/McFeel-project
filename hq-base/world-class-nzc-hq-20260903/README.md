## 口径

- “世界一流零碳总部”是愿景称呼；“一流”以可核验、可运行、可复制衡量，“零碳”是总目标与气质，不单独立为要素。
- 一核＝战略资产价值体系（四件资产），基地是验证场（内部验证—行业复制），不是第二增长曲线本身。
- 六要素：绿色、高效、智慧、普惠、健康、人文。健康独立于人文；普惠＝人人参与、人人受益（碳、算力、园区资源），无障碍是标配，不是投资收益、不是服务化产品。
- 基地是南网整体名片，能源公司只主笔起草，不是战略主体；复制先南网内园区，再其他央国企。
- 三层立意（国家六张网—南网六网协同、算电协同突破口—南网核心资产与第二增长曲线）只用来解释“为什么是这种总部”；“六张网 2030 覆盖重点园区”只作报道口径。
- 不编文号、不编精确数字、不用“首个/唯一/领先”；智慧手法参照中国移动国际信息港的预约联动与园区运营做法，不写成对标广告。
