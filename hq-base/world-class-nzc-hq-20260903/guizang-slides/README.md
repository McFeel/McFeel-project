# 世界一流零碳总部 · 横向翻页 HTML 幻灯

面向南方电网总部领导的方向汇报稿演示版本。单文件 HTML，`index.html`，双击即可投屏。

## 用了什么风格

按 [guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill) 的 **风格 B · 瑞士国际主义（Swiss Style）** 生成：

- 主题色：IKB 克莱因蓝（`--accent:#002FA7`），全场单一锚点色
- 版式：只使用 skill 登记的 `S01–S22` 正文版式与 `SWISS-COVER-ASCII` / `SWISS-CLOSING-ASCII` 首尾页，每页在 `<section>` 上写明 `data-layout`
- 排版：全程无衬线、直角纯色、发丝分割线、字号越大字重越轻（大字 200）
- 交互：键盘 ← →、滚轮、触屏滑动、底部翻页点、`ESC` 总览、`B` 低功耗静态、`P` 演讲者模式（含讲稿备注与观众屏同步）

## 主线是什么

内容口径以同目录的方向稿 `加快建设世界一流零碳总部_南网总部基地方向稿_2026-09-03.md` 为准，只回答两个问题，共 14 页。

**上篇：建成什么样（03–09 页）**
风貌不变、系统在跑、账算得清、人人在场、方法带得走的世界一流零碳总部。“一流”用可核验、可运行、可复制三条标准衡量；一核是战略资产价值体系（碳账与核算口径、调控与交易模型、数字底座与数据资产、改造与运营方法论），基地是这一核的验证场，不是第二增长曲线本身；六种气质是绿色、高效、智慧、普惠、健康、人文；零碳是总目标，不单列为第七个要素。

**下篇：为什么非此不可（10–13 页）**
国家需要存量园区的零碳答案，电网需要负荷侧的第一现场，南网需要第二增长曲线的信用与自持的主笔权，园区自身已经从“改不改”走到“怎么改”。最后一页只讲“若认同，第一步”——先立账、先跑通一个回路、先定平台口径，随后按程序转入预可行性研究。

不含项目清单、投资匡算、工期与分期安排；未经核证的数字与提法一律标注【待核】。

## 校验

```bash
node <SKILL_ROOT>/scripts/validate-swiss-deck.mjs index.html      # 版式锁 + 渲染测量
node <SKILL_ROOT>/scripts/validate-presenter-mode.mjs index.html  # 页面 ID / 讲稿备注
```

两个校验均为 0 error。剩余告警与 skill 原始模板 `template-swiss.html` 的基线一致（`canvas-card` 底部内边距与 split / ink 通栏页的满幅设计）。

## 目录

- `index.html` — 主文件，单文件可投屏
- `assets/motion.min.js` — Motion One 本地副本，断网时的动效兜底（缺失时自动降级为无动画但内容可读）
